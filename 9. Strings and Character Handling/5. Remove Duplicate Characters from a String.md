# Problem 5: Remove Duplicate Characters from a String

### Problem Statement

You are given a null-terminated string containing lowercase and uppercase letters, digits, symbols, or spaces.

Write a C program to remove all duplicate characters from the string in-place or into a new buffer, keeping only the first occurrence of each character. The original relative order of characters must be preserved.

### Input Format

- A single line containing a null-terminated string (maximum 100 characters).

### Output Format

- The string with duplicate characters removed.

### Example 1

#### Input

```
programming
```

#### Output

```
progamin
```

### Example 2 (Repeated adjacent characters)

#### Input

```
aabbcc
```

#### Output

```
abc
```

### Example 3 (String with spaces and case sensitivity)

#### Input

```
C language
```

#### Output

```
C langue
```

### Explanation

To remove duplicate characters while preserving order:

1. Maintain a tracking array or lookup table of seen characters (size 256 for standard ASCII).
2. Initialize a write index `write_idx = 0`.
3. Iterate through each character `c` of the string:
   - Check if `seen[(unsigned char)c]` is already set.
   - If not set, mark `seen[(unsigned char)c] = 1`, assign `str[write_idx++] = c`.
   - If already set, skip the character.
4. Append the null-terminator `'\0'` at `str[write_idx]`.

```
Example 1: "programming"
'p' -> not seen -> keep 'p'
'r' -> not seen -> keep 'r'
'o' -> not seen -> keep 'o'
'g' -> not seen -> keep 'g'
'r' -> seen     -> skip
'a' -> not seen -> keep 'a'
'm' -> not seen -> keep 'm'
'm' -> seen     -> skip
'i' -> not seen -> keep 'i'
'n' -> not seen -> keep 'n'
'g' -> seen     -> skip
Result: "progamin"
```

### Hints

- Use an array `int seen[256] = {0};` to track ASCII character occurrences in $O(1)$ time.
- Use a single pass with two indices (read index and write index) to perform the removal in-place.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void remove_duplicates(char *str) {
	//Your logic here
    int seen[256] = {0};
    int read = 0, write = 0;

    while (str[read] != '\0')
    {
        unsigned char ch = (unsigned char)str[read];
        if (seen[ch] == 0){
            seen[ch] = 1;
            str[write] = str[read];
            write++;
        }
        read++;
    }
    str[write] = '\0';
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    remove_duplicates(str);
    printf("%s", str);
    return 0;
}
```
