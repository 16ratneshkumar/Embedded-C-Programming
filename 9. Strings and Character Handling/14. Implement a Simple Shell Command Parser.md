# Problem 14: Implement a Simple Shell Command Parser

### Problem Statement

In embedded CLI (Command-Line Interface) firmware, input entered by a user or sent over serial console must be parsed into tokens (command name and its arguments). A lightweight parser separates each word (delimited by one or more spaces) into an array of strings.

Write a C program that reads a single command-line input string (up to 100 characters), splits it into individual argument tokens ignoring leading, trailing, or repeated spaces, and prints each token on its own line.

Do not use `strtok()` or string library functions other than reading input.

### Input Format

- A single line containing a command string (up to 100 characters).

### Output Format

- Each parsed token printed on a new line.

### Example 1 (Standard command and arguments)

#### Input

```
led set 3 on
```

#### Output

```
led
set
3
on
```

### Example 2 (Leading and multiple spaces)

#### Input

```
 uart   config 9600 8N1
```

#### Output

```
uart
config
9600
8N1
```

### Example 3 (Single command)

#### Input

```
status
```

#### Output

```
status
```

### Explanation

To parse tokens separated by variable whitespace:

1. Traverse the string while skipping any space characters `' '`.
2. When a non-space character is found, mark the start of a token.
3. Continue scanning until the next space `' '` or null terminator `'\0'`.
4. Copy or print the token characters, then print a newline.
5. Repeat until reaching the end of the input string.

```
Example 2: " uart   config 9600 8N1"
- Skip leading spaces
- Token 1: "uart"
- Skip intermediate spaces
- Token 2: "config"
- Skip intermediate spaces
- Token 3: "9600"
- Skip intermediate spaces
- Token 4: "8N1"
```

### Hints

- Use a while loop with an index or pointer traversing the input string.
- Skip whitespace (`c == ' ' || c == '\t'`) before each token.
- Read contiguous non-whitespace characters into a buffer and null-terminate before printing.

### Solution 1

```c
#include <stdio.h>
#include <ctype.h>

void parse_shell_input(char *line) {
    // Your logic here
    char field[10][101];
    int index = 0;
    int pos = 0;

    while (*line != '\0' && *line != '\n') {
        if (*line == ' ') {
            if (pos > 0){
                field[index][pos] = '\0';
                index++;
                pos = 0;
            }
        } else{
            field[index][pos++] = *line;
        }
        line++;
    }
    if (pos > 0) {
        field[index][pos] = '\0';
        index++;
    }
    for (int i = 0; i < index; i++) {
        printf("%s\n", field[i]);
    }
}

int main() {
    char line[101];
    fgets(line, sizeof(line), stdin);

    parse_shell_input(line);
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>
#include <ctype.h>

// Parse line and print each word (token) on a new line
void parse_shell_input(char *line) {
    int i = 0;
    int in_token = 0;

    while (line[i] != '\0' && line[i] != '\n') {
        if (isspace(line[i])) {
            if (in_token) {
                putchar('\n'); // End of a word
                in_token = 0;
            }
        } else {
            putchar(line[i]);
            in_token = 1;
        }
        i++;
    }

    if (in_token) {
        putchar('\n'); // End last token
    }
}

int main() {
    char line[101];
    fgets(line, sizeof(line), stdin);

    parse_shell_input(line);
    return 0;
}
```
