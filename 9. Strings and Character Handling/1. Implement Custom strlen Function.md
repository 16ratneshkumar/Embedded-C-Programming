# Problem 1: Implement Custom strlen Function

### Problem Statement

In C, strings are terminated by a null character `'\0'`. Implement a custom `strlen()` function that calculates the length of a string without using any built-in functions.

You will be given a string of maximum `100` characters. Return the number of characters before the null terminator.

### Input Format

- A single line string of at most `100` characters. The trailing newline is removed before processing.

### Output Format

- The number of characters before the null terminator.

### Example 1 (Non-empty string)

#### Input

```
Embedded
```

#### Output

```
8
```

### Example 2 (String with spaces)

#### Input

```
C is powerful
```

#### Output

```
13
```

### Example 3 (Empty string)

#### Input

```

```

#### Output

```
0
```

### Explanation

The function walks the string one character at a time and stops when it reaches `'\0'`. The number of steps taken is the length.

```
"Embedded"     -> E m b e d d e d \0 -> 8 characters
"C is powerful" -> 13 characters
""             -> \0 immediately       -> 0 characters
```

### Hints

- Start a counter at `0`.
- Increment the counter while `str[length] != '\0'`.
- Do not call the standard `strlen()`.

### Solution 1

```c
#include <stdio.h>

int custom_strlen(const char *str) {
    // Your logic here
    int length = 0;
    while (*str != '\0'){
        length++;
        str++;
    }
    return length;
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline if present
    int i = 0;
    while (str[i] != '\0') {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    printf("%d", custom_strlen(str));
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>

int custom_strlen(const char *str) {
    int length = 0;
    while (str[length] != '\0') {
        length++;  // Count until null terminator
    }
    return length;
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline if present
    int i = 0;
    while (str[i] != '\0') {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    printf("%d", custom_strlen(str));
    return 0;
}
```
