# Problem 7: Convert Uppercase Letters to Lowercase

### Problem Statement

You are given a null-terminated string of up to `100` characters.

Convert all uppercase letters (`A`-`Z`) to lowercase (`a`-`z`), leave all other characters unchanged (lowercase letters, digits, symbols, spaces), and perform the conversion in-place using only basic character logic.

Do not use standard functions like `tolower()`.

### Input Format

- A single line string of at most `100` characters. The trailing newline is removed before processing.

### Output Format

- The converted string.

### Example 1 (Mixed case)

#### Input

```
Hello Embedded
```

#### Output

```
hello embedded
```

### Example 2 (Uppercase with digits and symbols)

#### Input

```
C99 IS POWERFUL!
```

#### Output

```
c99 is powerful!
```

### Example 3 (Already lowercase)

#### Input

```
test123
```

#### Output

```
test123
```

### Explanation

In ASCII, each uppercase letter is exactly `32` positions before its lowercase form, so adding `32` to an uppercase character converts it. Characters outside `A`-`Z` are left untouched.

```
'H' -> 'h'   (72 + 32 = 104)
'E' -> 'e'   (69 + 32 = 101)
'9' -> '9'   (not in A-Z, unchanged)
'!' -> '!'   (not in A-Z, unchanged)
```

### Hints

- Check `'A' <= ch && ch <= 'Z'` before converting.
- Add `32` to the character value to reach its lowercase form.
- Modify the string in place; no extra buffer is needed.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void to_lowercase(char *str) {
    // Your logic here
    while (*str!='\0'){
        if ((('A' <= *str) && (*str <= 'Z'))){
            *str = (char) ((int)*str)+32;
        }
        str++;
    }
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    to_lowercase(str);
    printf("%s", str);
    return 0;
}
```
