# Problem 13: Parse GPS String for Time and Coordinates

### Problem Statement

In embedded systems interfacing with GPS modules, raw NMEA-0183 sentences such as `$GPRMC` are transmitted over UART. You are given a simplified `$GPRMC` string format:

`$GPRMC,<time>,<status>,<lat>,<NS>,<long>,<EW>,...`

Write a C program to extract and print:
- **UTC Time** formatted as `HH:MM:SS` (from the first field after `$GPRMC`)
- **Latitude with direction** formatted as `<lat> <NS>` (e.g. `4807.038 N`)
- **Longitude with direction** formatted as `<long> <EW>` (e.g. `01131.000 E`)

Assume:
- Input will always follow this valid comma-separated format.
- Only extract the first 7 fields; do not validate checksum or GPS fix status.
- Do not use string library functions other than reading input.

### Input Format

- A single line containing an NMEA `$GPRMC` string.

### Output Format

- Three lines displaying extracted time and coordinates:
  - `Time: HH:MM:SS`
  - `Latitude: <lat> <NS>`
  - `Longitude: <long> <EW>`

### Example 1

#### Input

```
$GPRMC,123519,A,4807.038,N,01131.000,E
```

#### Output

```
Time: 12:35:19
Latitude: 4807.038 N
Longitude: 01131.000 E
```

### Example 2

#### Input

```
$GPRMC,083559,A,3745.678,N,12227.890,W
```

#### Output

```
Time: 08:35:59
Latitude: 3745.678 N
Longitude: 12227.890 W
```

### Explanation

An NMEA `$GPRMC` sentence separates fields with commas:
- Field 0: Sentence header (`$GPRMC`)
- Field 1: UTC Time (`123519` -> `12:35:19`, formatted as `HH:MM:SS`)
- Field 2: Status (`A` = active)
- Field 3: Latitude value (`4807.038`)
- Field 4: North/South indicator (`N`)
- Field 5: Longitude value (`01131.000`)
- Field 6: East/West indicator (`E`)

Parsing splits tokens at each comma `,` and formats Field 1 into hours, minutes, and seconds (`HH:MM:SS`).

### Hints

- Tokenize the string by scanning for commas `,` without using `strtok()`.
- For the time field (`HHMMSS`), insert `:` between index 1 and 2, and between index 3 and 4 when printing.
- Print latitude alongside its N/S indicator and longitude alongside its E/W indicator.

### Solution 1

```c
#include <stdio.h>
#include <string.h>

void parse_gprmc(char *nmea) {
    char Time[10] = {0};
    char Status[2] = {0};
    char Latitude[15] = {0};
    char N_S_indicator[2] = {0};
    char Longitude[15] = {0};
    char E_W_indicator[2] = {0};

    int del_cnt = 0;
    int t = 0, s = 0, lat = 0, ns = 0, lon = 0, ew = 0;

    while (*nmea != '\0' && *nmea != '\n') {
        if (*nmea == ',') {
            del_cnt++;
        } 
        else if (del_cnt == 0) {
          continue;
        } 
        else if (del_cnt == 1) {
            if (t == 2 || t == 5) {
                Time[t++] = ':';
            }
            Time[t++] = *nmea;
        } 
        else if (del_cnt == 2) {
            Status[s++] = *nmea;
        } 
        else if (del_cnt == 3) {
            Latitude[lat++] = *nmea;
        } 
        else if (del_cnt == 4) {
            N_S_indicator[ns++] = *nmea;
        } 
        else if (del_cnt == 5) {
            Longitude[lon++] = *nmea;
        } 
        else if (del_cnt == 6) {
            E_W_indicator[ew++] = *nmea;
        }

        nmea++;
    }

    printf("Time: %s\nLatitude: %s %s\nLongitude: %s %s",Time, Latitude, N_S_indicator, Longitude, E_W_indicator);
}

int main() {
    char nmea[100];
    fgets(nmea, sizeof(nmea), stdin);
    parse_gprmc(nmea);
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>
#include <string.h>

// Parse simplified GPRMC sentence
void parse_gprmc(char *nmea) {
    char *fields[7];
    int index = 0;

    // Tokenize by comma
    char *token = strtok(nmea, ",");
    while (token != NULL && index < 7) {
        fields[index++] = token;
        token = strtok(NULL, ",");
    }

    // Extract time
    char *t = fields[1];
    printf("Time: %.2s:%.2s:%.2s\n", t, t+2, t+4);

    // Latitude
    printf("Latitude: %s %s\n", fields[3], fields[4]);

    // Longitude
    printf("Longitude: %s %s", fields[5], fields[6]);
}

int main() {
    char nmea[100];
    fgets(nmea, sizeof(nmea), stdin);
    parse_gprmc(nmea);
    return 0;
}
```
