# Problem 12: Split a String Using Delimiter

### Problem Statement

You are given a null-terminated string containing words separated by a delimiter character (such as `,` or a space).

Split the string into individual tokens based on the delimiter, store the tokens in a 2D array of characters (`char tokens[10][20]`), and print each token on a new line.

Do not use `strtok()` or any string library functions.

### Input Format

- A single line string of at most `100` characters.
- A delimiter character on the next line.

The trailing newline is removed from the string before processing.

### Output Format

- Each token on its own line.

### Example 1 (Comma delimiter)

#### Input

```
cmd1,cmd2,cmd3
,
```

#### Output

```
cmd1
cmd2
cmd3
```

### Example 2 (Space delimiter)

The second input line is a single space.

#### Input

```
ON OFF RESET
 
```

#### Output

```
ON
OFF
RESET
```

### Explanation

The parser walks the string one character at a time. Ordinary characters are appended to the current token. When the delimiter is found, the current token is terminated and the next row of the 2D array is started. After the loop ends, the last token is terminated and stored as well.

```
"cmd1,cmd2,cmd3" with ',' -> tokens: "cmd1", "cmd2", "cmd3"
"ON OFF RESET"   with ' ' -> tokens: "ON", "OFF", "RESET"
```

### Hints

- Keep a row index for the current token and a column index for the next character.
- On the delimiter, write `'\0'` at the current column, advance the row, and reset the column.
- After the loop ends, terminate and store the final token.
- Guard the row and column indices so the fixed `[10][20]` array is not overflowed.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void split_string(const char *str, char delimiter, char tokens[10][20], uint8_t *count) {
    int i = 0;
    int col = 0;
    while (str[i] != '\0'){
        if (*count >= 10){
            break;
        }
        if (str[i] == delimiter){
            tokens[*count][col] = '\0';

            (*count)++;
            col = 0;
        } else{
            if (col < 19 && *count < 10){
                tokens[*count][col++] = str[i];
            }
        }
        i++;
    }

    // Store the last token
    if (*count < 10){
        tokens[*count][col] = '\0';
        (*count)++;
    }
}


int main() {
    char str[101];
    char delimiter;
    fgets(str, sizeof(str), stdin);
    scanf("%c", &delimiter);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') { str[i] = '\0'; break; }
        i++;
    }

    char tokens[10][20];
    uint8_t count = 0;

    split_string(str, delimiter, tokens, &count);

    for (uint8_t i = 0; i < count; i++) {
        printf("%s\n", tokens[i]);
    }

    return 0;
}
```
