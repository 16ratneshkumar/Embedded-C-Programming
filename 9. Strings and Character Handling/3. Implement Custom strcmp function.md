# Problem 3: Implement Custom strcmp Function

### Problem Statement

You are given two null-terminated strings. Compare them character by character using ASCII values.

Return:

- `0` if all characters are the same and both strings end at the same time.
- The ASCII difference of the first mismatched characters otherwise: positive when the character in `a` is greater than the character in `b`, negative when it is smaller.

Do not use built-in functions like `strcmp()`.

### Input Format

- Two lines, each holding a string of at most `100` characters. The trailing newline is removed from each string.

### Output Format

- The comparison result as an integer.

### Example 1 (Equal strings)

#### Input

```
apple
apple
```

#### Output

```
0
```

### Example 2 (First characters differ)

#### Input

```
cat
bat
```

#### Output

```
1
```

### Example 3 (One string is a prefix of the other)

#### Input

```
abc
abcd
```

#### Output

```
-100
```

### Explanation

The function compares matching positions until the characters differ or a null terminator is reached.

```
"apple" vs "apple" -> all equal, both end together -> 0
"cat"   vs "bat"   -> 'c' - 'b' = 99 - 98 = 1
"abc"   vs "abcd"  -> 'a','b','c' match, then '\0' - 'd' = 0 - 100 = -100
```

### Hints

- Walk both strings with two pointers.
- Return `*a - *b` at the first mismatch.
- After the loop, return `*a - *b` to handle different lengths.

### Solution

```c
#include <stdio.h>

int custom_strcmp(const char *a, const char *b) {
    // Your logic here
    while ((*a != '\0') && (*b != '\0')){
        if ((*a != *b)){
            return (*a - *b);
        }
        a++;b++;
    }

    return (*a - *b);
}

int main() {
    char a[101], b[101];
    fgets(a, sizeof(a), stdin);
    fgets(b, sizeof(b), stdin);

    // Remove newline
    int i = 0;
    while (a[i]) {
        if (a[i] == '\n') { a[i] = '\0'; break; }
        i++;
    }
    i = 0;
    while (b[i]) {
        if (b[i] == '\n') { b[i] = '\0'; break; }
        i++;
    }

    printf("%d", custom_strcmp(a, b));
    return 0;
}
```
