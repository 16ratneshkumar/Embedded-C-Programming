# Problem 4: Reverse a String In-Place

### Problem Statement

You are given a null-terminated string (maximum 100 characters). Write a C program to reverse the string in-place without using any additional array or standard library functions like `strrev()`.

You must swap characters from both ends until the entire string is reversed. The null-terminator must remain at the end.

### Input Format

- A single line containing a null-terminated string (maximum 100 characters).

### Output Format

- The reversed string.

### Example 1

#### Input

```
firmware
```

#### Output

```
erawmrif
```

### Example 2 (String with spaces and digits)

#### Input

```
abc 123
```

#### Output

```
321 cba
```

### Explanation

Reversing in-place uses a two-pointer approach:

1. Determine string length `len` by counting characters until `'\0'`.
2. Initialize pointer/index `left = 0` and `right = len - 1`.
3. While `left < right`:
   - Swap `str[left]` with `str[right]`.
   - Increment `left` and decrement `right`.
4. The null-terminator at index `len` remains in place.

```
Example 1: "firmware" (len = 8)
Swap str[0] ('f') and str[7] ('e') -> "eirmwarf"
Swap str[1] ('i') and str[6] ('r') -> "errmwaif"
Swap str[2] ('r') and str[5] ('a') -> "eramwrif"
Swap str[3] ('m') and str[4] ('w') -> "erawmrif"
```

### Hints

- Find the length of the string manually by scanning until `'\0'`.
- Use two indices (`left = 0` and `right = len - 1`) and swap characters using a temporary `char` variable.
- Stop when `left >= right`.

### Solution 1

```c
#include <stdio.h>

void reverse_string(char *str) {
    // Your logic here
    char *tail_ptr = str;
    char *head_ptr = str;
    while(*tail_ptr != '\0'){
        tail_ptr++;
    }
    tail_ptr--;
    while (head_ptr <= tail_ptr){
        char temp= *tail_ptr;
        *tail_ptr = *head_ptr;
        *head_ptr = temp;
        tail_ptr--;
        head_ptr++;
    }    
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    int i = 0;
    while (str[i] != '\0') {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    reverse_string(str);
    printf("%s", str);
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>

void reverse_string(char *str) {
    int start = 0;
    int end = 0;

    // Find length of string
    while (str[end] != '\0') {
        end++;
    }
    end--;  // Move to last valid character

    // Swap characters from both ends
    while (start < end) {
        char temp = str[start];
        str[start] = str[end];
        str[end] = temp;
        start++;
        end--;
    }
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    int i = 0;
    while (str[i] != '\0') {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    reverse_string(str);
    printf("%s", str);
    return 0;
}
```
