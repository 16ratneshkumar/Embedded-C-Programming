# Problem 10: Check if the String Numeric or Alphabetic

### Problem Statement

You are given a null-terminated input string. Classify it as follows:

- Print `NUMERIC` if the string contains only digits (`0`-`9`).
- Print `ALPHABETIC` if the string contains only letters (`A`-`Z`, `a`-`z`).
- Otherwise, print `MIXED` if it contains anything else (symbols, a mix of digits and letters, or an empty string).

Do not use standard library functions like `isdigit()` or `isalpha()`. Use only ASCII value checks.

### Input Format

- A single line string of at most `100` characters. The trailing newline is removed before processing.

### Output Format

- `NUMERIC`, `ALPHABETIC`, or `MIXED`.

### Example 1 (All digits)

#### Input

```
123456
```

#### Output

```
NUMERIC
```

### Example 2 (All letters)

#### Input

```
firmwareC
```

#### Output

```
ALPHABETIC
```

### Example 3 (Digits and letters)

#### Input

```
C99
```

#### Output

```
MIXED
```

### Example 4 (Letters and symbol)

#### Input

```
Hello!
```

#### Output

```
MIXED
```

### Example 5 (Empty string)

#### Input

```

```

#### Output

```
MIXED
```

### Explanation

Two flags start as `1`. A digit clears the alphabetic flag, a letter clears the numeric flag, and any other character clears both. The surviving flag decides the classification. An empty string is treated as `MIXED`.

```
"123456"   -> digits only        -> NUMERIC
"firmwareC"-> letters only       -> ALPHABETIC
"C99"      -> digits and letters -> MIXED
"Hello!"   -> letter and symbol  -> MIXED
""         -> no characters      -> MIXED
```

### Hints

- Use two flags, `numeric` and `alphabetic`, both starting at `1`.
- Clear the opposite flag when you see a digit or a letter.
- Handle the empty string before the loop.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void classify_string(const char *str){
    // Your logic here
    int numeric = 1;
    int alphabetic = 1;

    if (*str == '\0') {
        printf("MIXED");
        return;
    }

    while (*str != '\0'){
        if (*str >= '0' && *str <= '9'){
            alphabetic = 0;
        }
        else if ((*str >= 'a' && *str <= 'z') || (*str >= 'A' && *str <= 'Z')){
            numeric = 0;
        }
        else {
            numeric = 0;
            alphabetic = 0;
        }
        str++;
    }

    if (numeric)
        printf("NUMERIC");
    else if (alphabetic)
        printf("ALPHABETIC");
    else
        printf("MIXED");
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    classify_string(str);
    return 0;
}
```
