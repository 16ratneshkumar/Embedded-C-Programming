# Problem 11: Convert a String to Float

### Problem Statement

You are given a null-terminated string representing a floating-point number, which may contain:
- An optional sign (`+` or `-`)
- An optional decimal point (`.`)
- Only valid decimal digits (`0`–`9`) and at most one dot

Write a C program to convert this string to its floating-point value (`float`), without using standard library functions like `atof()`, `strtof()`, or `sscanf()`.

Do not handle scientific notation (e.g., `"1.2e5"`). Print the resulting float with 2 decimal places.

### Input Format

- A single line containing a null-terminated string representing a valid floating-point number.

### Output Format

- The converted floating-point number printed to 2 decimal places.

### Example 1 (Standard positive float)

#### Input

```
123.45
```

#### Output

```
123.45
```

### Example 2 (Negative float)

#### Input

```
-0.75
```

#### Output

```
-0.75
```

### Example 3 (Whole integer string)

#### Input

```
100
```

#### Output

```
100.00
```

### Example 4 (Leading positive sign)

#### Input

```
+9.99
```

#### Output

```
9.99
```

### Explanation

To convert a string to a floating-point number:

1. **Sign**: Check the first character for `'+'` or `'-'`. Set sign multiplier to `-1.0` if `'-'`, else `1.0`.
2. **Integer Part**: Read digits before the decimal point (`'.'`), accumulating `int_part = int_part * 10 + (c - '0')`.
3. **Fractional Part**: If a `'.'` is encountered, read subsequent digits while maintaining a divisor (`divisor = 10.0, 100.0, ...`), adding `(c - '0') / divisor` to the fractional part.
4. **Combine**: The final value is `sign * (int_part + frac_part)`.

```
Example 1: "123.45"
Integer part: 1 -> 12 -> 123
Dot encountered
Fractional part:
  '4' -> + 4 / 10 = 0.4
  '5' -> + 5 / 100 = 0.05
Total: 123 + 0.45 = 123.45
```

### Hints

- Traverse the string sequentially, handling the optional sign first.
- Track whether you are parsing before or after the decimal point.
- For each fractional digit, multiply a weight variable by `0.1f` or divide by `10.0f`.

### Solution 1

```c
#include <stdio.h>
#include <stdint.h>

float custom_atof(const char *str) {
    float num = 0;
    int count = 0;
    int sign = 1;
    if (str[0] == '+'){
        str++;
    } else if (str[0] == '-'){
        str++;
        sign= -1;
    };
    while (*str != '\0'){
        if (*str >= '0' && *str <= '9'){
            num = num * 10 + (*str - '0');
            count*=10;
        } else if (*str == '.'){
            count = 1;
        } else {
            break;
        }
        str++;
    }
    if (count == 0) count = 1;
    return sign*(num / count);
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    float value = custom_atof(str);
    printf("%.2f", value);
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>
#include <stdint.h>

float custom_atof(const char *str) {
    float result = 0.0f;
    float fraction = 0.0f;
    float divisor = 10.0f;
    int sign = 1;
    uint8_t i = 0;
    uint8_t in_fraction = 0;

    // Handle optional sign
    if (str[i] == '-') {
        sign = -1;
        i++;
    } else if (str[i] == '+') {
        i++;
    }

    while (str[i] != '\0') {
        if (str[i] == '.') {
            in_fraction = 1;
            i++;
            continue;
        }

        if (str[i] >= '0' && str[i] <= '9') {
            int digit = str[i] - '0';
            if (!in_fraction) {
                result = result * 10.0f + digit;
            } else {
                fraction += digit / divisor;
                divisor *= 10.0f;
            }
        } else {
            break;  // Stop if non-digit, non-dot char
        }
        i++;
    }

    return sign * (result + fraction);
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    float value = custom_atof(str);
    printf("%.2f", value);
    return 0;
}
```
