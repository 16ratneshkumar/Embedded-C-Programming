# Problem 9: Convert String to Integer

### Problem Statement

You are given a null-terminated string that may contain:

- An optional sign (`+` or `-`) at the beginning.
- A numeric part made of digits.
- Other non-digit characters (letters, symbols) that should be ignored once they appear.

Convert the initial numeric part of the string to an integer, stop parsing when a non-digit character is encountered, and return the result with the correct sign.

Do not use `atoi()`, `strtol()`, or similar built-in functions.

### Input Format

- A single line string of at most `100` characters. The trailing newline is removed before processing.

### Output Format

- The converted integer, or `0` when the string does not start with a numeric part.

### Example 1 (Digits followed by letters)

#### Input

```
123abc
```

#### Output

```
123
```

### Example 2 (Negative number)

#### Input

```
-45!
```

#### Output

```
-45
```

### Example 3 (Digits followed by symbols)

#### Input

```
42@#
```

#### Output

```
42
```

### Example 4 (No leading digits)

#### Input

```
abc123
```

#### Output

```
0
```

### Example 5 (Explicit positive sign)

#### Input

```
+78x90
```

#### Output

```
78
```

### Explanation

An optional leading sign sets the sign multiplier. Digits are accumulated until the first non-digit, at which point parsing stops and the result is returned with the stored sign.

```
"123abc" -> 123, then 'a' stops parsing -> 123
"-45!"   -> sign -1, digits 45, then '!' stops -> -45
"42@#"   -> 42, then '@' stops -> 42
"abc123" -> 'a' is not a digit -> 0
"+78x90" -> sign +1, digits 78, then 'x' stops -> 78
```

### Hints

- Consume an optional leading `+` or `-` before the digit loop.
- Accumulate with `num = num * 10 + (*str - '0');`.
- Break out of the loop on the first non-digit and multiply by the sign.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

int custom_atoi(const char *str) {
    // Your logic here
    int num = 0;
    int sign = 1;
    if (str[0] == '+'){
        str++;
    } else if (str[0] == '-'){
        str++;
        sign= -1;
    };
    while (*str != '\0'){
        if (*str >= '0' && *str <= '9'){
            num = num * 10 + (*str - '0');
        }
        else {
            break;
        }
        str++;
    }
    return num*sign;
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    printf("%d", custom_atoi(str));
    return 0;
}
```
