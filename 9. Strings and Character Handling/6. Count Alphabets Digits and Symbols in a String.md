# Problem 6: Count Alphabets, Digits and Symbols in a String

### Problem Statement

You are given a null-terminated string containing alphabets, digits, symbols, and spaces. Count the number of:

- Alphabets (`A`-`Z`, `a`-`z`)
- Digits (`0`-`9`)
- Other symbols (anything that is not an alphabet, digit, or space)

Avoid using standard library functions like `isalpha()` or `isdigit()`.

### Input Format

- A single line string of at most `100` characters. The trailing newline is removed before processing.

### Output Format

- Three lines in this exact form:

```
Alphabets = <count>
Digits = <count>
Symbols = <count>
```

### Example 1 (Mixed string)

#### Input

```
C99_Firmware!
```

#### Output

```
Alphabets = 9
Digits = 2
Symbols = 2
```

### Example 2 (Digits and symbols)

#### Input

```
123@hello#
```

#### Output

```
Alphabets = 5
Digits = 3
Symbols = 2
```

### Explanation

Each character is classified by range checks. Spaces are ignored, so they are not counted as symbols.

```
"C99_Firmware!" -> C, F, i, r, m, w, a, r, e -> 9 alphabets
                   9, 9                       -> 2 digits
                   _, !                       -> 2 symbols

"123@hello#"    -> h, e, l, l, o             -> 5 alphabets
                   1, 2, 3                     -> 3 digits
                   @, #                        -> 2 symbols
```

### Hints

- Check digits with `'0' <= ch && ch <= '9'`.
- Check alphabets with `('A' <= ch && ch <= 'Z') || ('a' <= ch && ch <= 'z')`.
- Count a symbol only when the character is not a space.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void classify_chars(const char *str, uint8_t *alpha, uint8_t *digit, uint8_t *symbol) {
    // Your logic here
    char chr;
    while (*str != '\0'){
        chr = *str;
        if (('0'<= chr) && (chr <='9')){
            *digit+= 1;
        } else if ((('A'<= chr) && ('Z'>= chr))|| (('a'<= chr) && ('z'>= chr))){
            *alpha+= 1;
        }else if (chr != ' '){
            *symbol += 1;
        }
        str++;
    }
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    uint8_t alpha = 0, digit = 0, symbol = 0;
    classify_chars(str, &alpha, &digit, &symbol);
    printf("Alphabets = %u\nDigits = %u\nSymbols = %u", alpha, digit, symbol);
    return 0;
}
```
