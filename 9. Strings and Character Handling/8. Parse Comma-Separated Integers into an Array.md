# Problem 8: Parse Comma-Separated Integers into an Array

### Problem Statement

You are given a comma-separated string of integers (e.g., `"10,20,30"`). Each number is in the range `0`-`255`.

Parse the string and extract all numbers into an array of integers.

- Use only basic string logic (do not use `strtok()` or standard tokenizing functions).
- Stop at the null terminator (`'\0'`).
- Store the results into a `uint8_t[]` array and print them.

### Input Format

- A single line string of comma-separated integers, at most `100` characters. Each number is in the range `0`-`255`.

### Output Format

- The parsed numbers separated by single spaces.

### Example 1 (Three numbers)

#### Input

```
10,20,30
```

#### Output

```
10 20 30
```

### Example 2 (Single number)

#### Input

```
5
```

#### Output

```
5
```

### Example 3 (Five numbers)

#### Input

```
1,2,3,4,5
```

#### Output

```
1 2 3 4 5
```

### Explanation

The parser accumulates digits into the current number. A comma stores the accumulated number and resets it. After the loop ends, the last accumulated number is stored as well.

```
"10,20,30" -> 10 | comma -> store 10
              20 | comma -> store 20
              30 | end   -> store 30
"5"        -> 5  | end   -> store 5
```

### Hints

- Build each number with `num = num * 10 + (*str - '0');`.
- On `,`, store `num` and reset it to `0`.
- Do not forget to store the final number after the loop ends.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void parse_csv_to_array(const char *str, uint8_t *arr, uint8_t *count) {
    // Your logic here
    uint8_t num = 0;
    while (*str != '\0'){
        if (*str >= '0' && *str <= '9'){
            num = num * 10 + (*str - '0');
        }
        else if (*str == ','){
            arr[(*count)++] = num;
            num = 0;
        }
        str++;
    }
    arr[(*count)++] = num;
}

int main() {
    char str[101];
    fgets(str, sizeof(str), stdin);

    // Remove newline
    uint8_t i = 0;
    while (str[i]) {
        if (str[i] == '\n') {
            str[i] = '\0';
            break;
        }
        i++;
    }

    uint8_t arr[100];
    uint8_t count = 0;

    parse_csv_to_array(str, arr, &count);

    for (uint8_t i = 0; i < count; i++) {
        printf("%u", arr[i]);
        if(i < count - 1){
            printf(" ");
        }
    }
    return 0;
}
```
