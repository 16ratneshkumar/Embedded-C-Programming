# Problem 1: Linear Search in an Array

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`) and a key. Write a C program to find the first occurrence of the key using a loop and index logic only.

If the key is found, print its zero-based index. If it is not found, print `-1`.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers representing the array.
- An unsigned 8-bit integer `key` to search for.

The array contains at most 100 elements.

### Output Format

- The zero-based index of the first occurrence of `key`.
- Print `-1` if the key does not occur in the array.

### Example 1 (Key found)

#### Input

```
5
10 20 30 40 50
30
```

#### Output

```
2
```

### Example 2 (Key not found)

#### Input

```
4
5 8 12 9
7
```

#### Output

```
-1
```

### Example 3 (Repeated key)

#### Input

```
6
1 1 2 3 1 4
1
```

#### Output

```
0
```

### Explanation

The search scans the array from index 0 toward the last element. It returns immediately when the key is first found, so repeated values produce the index of their first occurrence.

### Hints

- Compare each array element with `key`.
- Return the current index as soon as the values match.
- Return `-1` after the loop finishes without a match.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

int linear_search(uint8_t *arr, uint8_t n, uint8_t key) {
    for (int i=0;i<n;i++) {
        if (*(arr+i) == key ){
            return i;
        }
    }
    return -1;
}

int main() {
    uint8_t n, key;
    scanf("%hhu", &n);
    uint8_t arr[100];

    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }
    scanf("%hhu", &key);

    int index = linear_search(arr, n, key);
    printf("%d", index);
    return 0;
}
```
