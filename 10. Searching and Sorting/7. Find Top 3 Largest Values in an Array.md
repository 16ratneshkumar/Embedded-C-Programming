# Problem 7: Find Top 3 Largest Values in an Array

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`). Write a C program that finds the top 3 largest values from the array and prints them in descending order.

If `n < 3`, print all available values in descending order. Do not use any built-in sort functions; use simple logic.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers representing the array.

The array contains at most 100 elements.

### Output Format

- The top 3 largest values as space-separated values, in descending order.
- If `n < 3`, print all available values in descending order.

### Example 1 (Typical case)

#### Input

```
6
10 90 20 80 70 30
```

#### Output

```
90 80 70
```

### Example 2 (Fewer than 3 elements)

#### Input

```
2
5 200
```

#### Output

```
200 5
```

### Example 3 (Exactly 3 elements)

#### Input

```
3
1 2 3
```

#### Output

```
3 2 1
```

### Explanation

The array is sorted in descending order first. Then only the first `3` elements are printed, or all elements when `n` is smaller than 3.

### Hints

- Sort the array in descending order.
- Print the first `3` values, or `n` values when `n < 3`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void find_top_3(uint8_t *arr, uint8_t n) {
    // Your logic here
    for (int i=0;i<n;i++){
        for (int j=0; j < n-i-1; j++){
            if (arr[j] < arr[j+1]){
                uint8_t temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;

            }
        }
    }
    uint8_t limit = (n < 3) ? n : 3;
    for (uint8_t i = 0; i < limit; i++) {
        printf("%hhu", arr[i]);
        if(i < limit-1){
            printf(" ");
        }
    }
}

int main() {
    uint8_t n;
    scanf("%hhu", &n);
    uint8_t arr[100];

    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }

    find_top_3(arr, n);
    return 0;
}
```
