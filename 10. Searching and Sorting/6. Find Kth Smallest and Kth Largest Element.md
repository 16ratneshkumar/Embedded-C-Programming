# Problem 6: Find Kth Smallest and Kth Largest Element

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`) and a number `k`. Write a C program that finds the k-th smallest and k-th largest values from the array.

Output both values in a single line: `smallest largest`. Assume `1 ≤ k ≤ n`. Do not use built-in sort functions; use a simple sorting approach (bubble/selection) and pick elements by index.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers representing the array.
- An integer `k`, where `1 ≤ k ≤ n`.

The array contains at most 100 elements.

### Output Format

- The k-th smallest and k-th largest values, separated by a space.

### Example 1 (k inside the array)

#### Input

```
5
10 3 5 2 7
2
```

#### Output

```
3 7
```

### Example 2 (k = 1)

#### Input

```
4
8 1 9 6
1
```

#### Output

```
1 9
```

### Example 3 (k = n)

#### Input

```
3
10 20 30
3
```

#### Output

```
30 10
```

### Explanation

After sorting the array in ascending order, the k-th smallest element is at index `k-1` and the k-th largest element is at index `n-k`. Both are read directly from the sorted array.

### Hints

- Sort the array in ascending order first.
- The k-th smallest is `arr[k-1]`.
- The k-th largest is `arr[n-k]`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void sort_array(uint8_t *arr, uint8_t n) {
    // Sort in ascending order
    for (int i=0;i<n;i++){
        for (int j=0; j < n-i-1; j++){
            if (arr[j] > arr[j+1]){
                uint8_t temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;

            }
        }
    }
}

void find_kth_elements(uint8_t *arr, uint8_t n, uint8_t k, uint8_t *smallest, uint8_t *largest) {
    // Your logic here
    sort_array(arr, n);
    *smallest = arr[k-1];
    *largest = arr[n-k];
}

int main() {
    uint8_t n, k;
    scanf("%hhu", &n);
    uint8_t arr[100];
    
    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }

    scanf("%hhu", &k);

    uint8_t smallest, largest;
    find_kth_elements(arr, n, k, &smallest, &largest);

    printf("%hhu %hhu", smallest, largest);
    return 0;
}
```
