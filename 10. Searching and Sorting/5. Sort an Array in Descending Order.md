# Problem 5: Sort an Array in Descending Order

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`). Write a C program that sorts the array in descending order using the bubble sort algorithm.

Print the sorted array as space-separated values. Do not use any built-in sort functions; use only loops and comparisons.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers representing the array.

The array contains at most 100 elements.

### Output Format

- The sorted array as space-separated values, in descending order.

### Example 1 (Typical case)

#### Input

```
5
10 3 5 2 7
```

#### Output

```
10 7 5 3 2
```

### Example 2 (Ascending input)

#### Input

```
3
0 128 255
```

#### Output

```
255 128 0
```

### Example 3 (Single element)

#### Input

```
1
42
```

#### Output

```
42
```

### Explanation

Bubble sort passes over the array comparing adjacent pairs and swapping them when the left value is smaller than the right one. After each pass, the smallest remaining value settles at the end, until the entire array is sorted in descending order.

### Hints

- Use two nested loops.
- The inner loop compares `arr[j]` with `arr[j+1]` and swaps when `arr[j] < arr[j+1]`.
- After each outer pass, the inner loop range can shrink.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void bubble_sort_desc(uint8_t *arr, uint8_t n) {
    // Your logic here
    for (int i=0;i<n;i++){
        for (int j=0; j < n-i-1; j++){
            if (arr[j] < arr[j+1]){
                uint8_t temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;

            }
        }
    }
}

int main() {
    uint8_t n;
    scanf("%hhu", &n);
    uint8_t arr[100];

    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }

    bubble_sort_desc(arr, n);

    for (uint8_t i = 0; i < n; i++) {
        printf("%hhu", arr[i]);
        if(i < n-1){
            printf(" ");
        }
    }

    return 0;
}
```
