# Problem 4: Sort an Array in Ascending Order

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`). Write a C program that sorts the array in ascending order using only loop and comparison logic (firmware-safe implementation).

Print the sorted array as space-separated values. Do not use any standard library sort functions.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers representing the array.

The array contains at most 100 elements.

### Output Format

- The sorted array as space-separated values, in ascending order.

### Example 1 (Typical case)

#### Input

```
5
10 3 5 2 7
```

#### Output

```
2 3 5 7 10
```

### Example 2 (Includes boundary values)

#### Input

```
3
255 0 128
```

#### Output

```
0 128 255
```

### Example 3 (Single element)

#### Input

```
1
42
```

#### Output

```
42
```

### Explanation

Bubble sort repeatedly passes over the array, comparing adjacent pairs and swapping them when the left value is greater than the right one. After each pass, the largest remaining value settles at the end, so the loop range shrinks by one until the whole array is sorted.

### Hints

- Use two nested loops.
- The inner loop compares `arr[j]` with `arr[j+1]` and swaps when out of order.
- After each outer pass, the inner loop range can shrink because the last value is already in place.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void bubble_sort(uint8_t *arr, uint8_t n) {
    for (int i=0;i<n;i++){
        for (int j=0; j < n-i-1; j++){
            if (arr[j] > arr[j+1]){
                uint8_t temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;

            }
        }
    }
}

int main() {
    uint8_t n;
    scanf("%hhu", &n);
    uint8_t arr[100];

    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }

    bubble_sort(arr, n);

    for (uint8_t i = 0; i < n; i++) {
        printf("%hhu", arr[i]);
        if(i < n-1){
            printf(" ");
        }
    }

    return 0;
}
```
