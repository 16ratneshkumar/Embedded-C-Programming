# Problem 3: Find the Minimum and Maximum in an Array

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`). Write a C program to find the minimum and maximum values in the array.

Print both values on one line, with the minimum first and the maximum second.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers representing the array.

The array contains at most 100 elements.

### Output Format

- The minimum value followed by the maximum value, separated by one space.

### Example 1 (Mixed values)

#### Input

```
5
10 20 5 30 15
```

#### Output

```
5 30
```

### Example 2 (Full 8-bit range values)

#### Input

```
3
255 0 128
```

#### Output

```
0 255
```

### Example 3 (One-element array)

#### Input

```
1
42
```

#### Output

```
42 42
```

### Explanation

Initialize both results with the first array element. Scan the remaining elements and update the minimum when a smaller value is found and the maximum when a larger value is found. For a one-element array, both results remain equal to that element.

### Hints

- Use the first array element as the initial minimum and maximum.
- Compare each value with both current results.
- Pass the result variables by pointer if the helper function must update them.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void find_min_max(uint8_t *arr, uint8_t n, uint8_t *min, uint8_t *max) {
    *min=arr[0];
    *max=arr[0];
    for (int i=0;i<n;i++){
        if (*max<arr[i]) *max = arr[i];
        if (arr[i]<*min) *min = arr[i];
    }
}

int main() {
    uint8_t n;
    scanf("%hhu", &n);
    uint8_t arr[100];

    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }

    uint8_t min_val, max_val;
    find_min_max(arr, n, &min_val, &max_val);

    printf("%hhu %hhu", min_val, max_val);
    return 0;
}
```
