# Problem 2: Binary Search in a Sorted Array

### Problem Statement

You are given an array of `n` unsigned 8-bit integers (`uint8_t`) sorted in ascending order and a key to search for.

Write a C program that uses an iterative binary search to find the key. Print its zero-based index if it is found; otherwise, print `-1`.

### Input Format

- An integer `n`, the number of array elements.
- `n` unsigned 8-bit integers in ascending order.
- An unsigned 8-bit integer `key` to search for.

The array contains at most 100 elements and is guaranteed to be sorted in ascending order.

### Output Format

- The zero-based index of `key` if it is present.
- Print `-1` if the key is not present.

### Example 1 (Key found in the middle)

#### Input

```
6
5 10 15 20 25 30
20
```

#### Output

```
3
```

### Example 2 (Key not found)

#### Input

```
5
2 4 6 8 10
1
```

#### Output

```
-1
```

### Example 3 (Key at the last index)

#### Input

```
4
100 150 200 250
250
```

#### Output

```
3
```

### Explanation

Binary search checks the middle element of the current range. If the middle value is smaller than the key, it searches the right half. If it is larger, it searches the left half. The process continues until the key is found or the search range becomes empty.

### Hints

- Start with `low = 0` and `high = n - 1`.
- Calculate the middle index with `low + (high - low) / 2`.
- Update only one boundary after each comparison.
- Use a loop; do not use recursion.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

int binary_search(uint8_t *arr, uint8_t n, uint8_t key) {
        int low = 0;
        int high = n - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] == key) {
                return mid; // Key found
            } else if (arr[mid] < key) {
                low = mid + 1; // Search right half
            } else {
                high = mid - 1; // Search left half
            }
        }
        return -1; // Key not found
}

int main() {
    uint8_t n, key;
    scanf("%hhu", &n);
    uint8_t arr[100];

    for (uint8_t i = 0; i < n; i++) {
        scanf("%hhu", &arr[i]);
    }
    scanf("%hhu", &key);

    int index = binary_search(arr, n, key);
    printf("%d", index);
    return 0;
}
```
