# 🧩 Problem 11: Decode Status Register into Human-Readable Flags

### 📝 Problem Statement

In embedded systems, status registers often represent multiple flags using each bit. You are given an **8-bit status register**. Each bit corresponds to a different condition.

**Bit-to-Flag Mapping**

| Bit | Meaning       |
|:---:|---------------|
| 0   | Power On      |
| 1   | Error         |
| 2   | Tx Ready      |
| 3   | Rx Ready      |
| 4   | Overheat      |
| 5   | Undervoltage  |
| 6   | Timeout       |
| 7   | Reserved      |

Write a function that:

* Accepts a `uint8_t status_reg`.
* Decodes which flags are set (bits = 1).
* Prints only the enabled flag names, one per line, in the order of bits from LSB to MSB (0 to 7).

### 🧾 Input Format

- An unsigned 8-bit integer (`0-255`) representing the status register value.
- Bit positions are zero-based, where bit 0 is the least significant bit.

### 📤 Output Format

- The names of all enabled flags, one per line (Bits `0` to `7`), or nothing if no bits are set.

### ✅ Example 1 (Decode `13`)

#### Input

```
13
```

#### Output

```
Power On
Tx Ready
Rx Ready
```

#### 🔍 Explanation

```
13               = 00001101
Bit 0 set        -> Power On
Bit 2 set        -> Tx Ready
Bit 3 set        -> Rx Ready
```

### ✅ Example 2 (Decode `48`)

#### Input

```
48
```

#### Output

```
Overheat
Undervoltage
```

#### 🔍 Explanation

```
48              = 00110000
Bit 4 set       -> Overheat
Bit 5 set       -> Undervoltage
```

### ✅ Example 3 (Decode `255`)

#### Input

```
255
```

#### Output

```
Power On
Error
Tx Ready
Rx Ready
Overheat
Undervoltage
Timeout
Reserved
```

#### 🔍 Explanation

`255 = 11111111`, so every bit is set and all eight flag names are printed from Bit `0` to Bit `7`.

### 💡 Hints

- Loop over bit positions `0` to `7`.
- Test each bit with `(status_reg >> i) & 1`.
- Use an array of flag name strings indexed by bit position.

### 💻 Solution

```c
#include <stdio.h>
#include <stdint.h>

const char* flag_names[8] = {
    "Power On",      // Bit 0
    "Error",         // Bit 1
    "Tx Ready",      // Bit 2
    "Rx Ready",      // Bit 3
    "Overheat",      // Bit 4
    "Undervoltage",  // Bit 5
    "Timeout",       // Bit 6
    "Reserved"       // Bit 7
};

void decode_status(uint8_t status_reg) {
    // Your logic here
    for (int i=0;i<8;i++)
    {
       if ((status_reg >> i) & 1){
        printf("%s\n",flag_names[i]);
       }
    }
}

int main() {
    uint8_t reg;
    scanf("%hhu", &reg);
    decode_status(reg);
    return 0;
}
```
