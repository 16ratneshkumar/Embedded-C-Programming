# 🧩 Problem 10: Bit Operations Using Macros

### 📝 Problem Statement

In embedded systems, modifying specific bits of a control or status register is a common task.

Write a **C program** that accepts an 8-bit register value and applies these operations in order:

1. Set bits 2 and 7.
2. Clear bit 3.
3. Toggle bit 5.

Define a separate bitwise macro for each operation. Return and print the updated register value.

### 🧾 Input Format

- An unsigned 8-bit integer (`0-255`) representing the register value.
- Bit positions are zero-based, where bit 0 is the least significant bit.

### 📤 Output Format

- The updated register value as an unsigned decimal integer.

### ✅ Example 1 (All bits initially clear)

#### Input

```
0
```

#### Output

```
164
```

#### 🔍 Explanation

```
Initial value       = 00000000
Set bits 2 and 7    = 10000100
Clear bit 3         = 10000100
Toggle bit 5        = 10100100
Decimal output      = 164
```

### ✅ Example 2 (All bits initially set)

#### Input

```
255
```

#### Output

```
215
```

#### 🔍 Explanation

```
Initial value       = 11111111
Set bits 2 and 7    = 11111111
Clear bit 3         = 11110111
Toggle bit 5        = 11010111
Decimal output      = 215
```

### ✅ Example 3 (Selected bits initially set)

#### Input

```
36
```

#### Output

```
132
```

#### 🔍 Explanation

```
Initial value       = 00100100
Set bits 2 and 7    = 10100100
Clear bit 3         = 10100100
Toggle bit 5        = 10000100
Decimal output      = 132
```

### 💡 Hints

- Use bitwise OR (`|`) to set bits.
- Use bitwise AND with an inverted mask (`& ~`) to clear a bit.
- Use bitwise XOR (`^`) to toggle a bit.
- Parenthesize macro parameters and the complete expression.

### 💻 Solution

```c
#include <stdint.h>
#include <stdio.h>

#define SET_BITS_2_AND_7(value) ((value) | ((uint8_t)1u << 2) | ((uint8_t)1u << 7))
#define CLEAR_BIT_3(value) ((value) & (uint8_t)~((uint8_t)1u << 3))
#define TOGGLE_BIT_5(value) ((value) ^ ((uint8_t)1u << 5))

uint8_t modify_register(uint8_t reg) {
    reg = SET_BITS_2_AND_7(reg);
    reg = CLEAR_BIT_3(reg);
    reg = TOGGLE_BIT_5(reg);
    return reg;
}

int main(void) {
    unsigned int input;
    scanf("%u", &input);
    uint8_t reg = (uint8_t)input;
    printf("%u\n", (unsigned int)modify_register(reg));
    return 0;
}
```
