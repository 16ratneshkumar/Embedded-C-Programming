# 🧩 Problem 13: Macro-Based Register Config Helper

### 📝 Problem Statement

In embedded systems, registers are often configured by setting specific bits. To make the code cleaner and reusable, firmware developers use macros to set fields in a register.

You are given a **16-bit control register** with this layout:

| Field    | Width | Position (LSB-first) |
|----------|:-----:|:---------------------:|
| ENABLE   | 1     | Bit 0                 |
| MODE     | 2     | Bits 1–2              |
| SPEED    | 3     | Bits 3–5              |
| RESERVED | 2     | Bits 6–7 (must be 0)  |

Write macros to:

- Set the `ENABLE` bit.
- Set the `MODE` field.
- Set the `SPEED` field.

Read `ENABLE`, `MODE`, and `SPEED` from input, then use the macros to pack a final **16-bit** register value. The `RESERVED` bits (6–7) must be left `0`.

### 🧾 Input Format

- Three unsigned integers on one line, in the order: `enable mode speed`.
- `enable`: `0` or `1`.
- `mode`: integer in range `0-3`.
- `speed`: integer in range `0-7`.

### 📤 Output Format

- The packed 16-bit register value as an unsigned decimal integer.

### ✅ Example 1 (enable = `1`, mode = `2`, speed = `4`)

#### Input

```
1 2 4
```

#### Output

```
37
```

#### 🔍 Explanation

```
ENABLE bit (1 << 0) = 0000000000000001
MODE  field (2 << 1) = 0000000000000100
SPEED field (4 << 3) = 0000000000100000
Register value       = 0000000000100101 = 0x25 = 37
```

### ✅ Example 2 (enable = `0`, mode = `1`, speed = `3`)

#### Input

```
0 1 3
```

#### Output

```
26
```

#### 🔍 Explanation

```
ENABLE bit (0 << 0) = 0000000000000000
MODE  field (1 << 1) = 0000000000000010
SPEED field (3 << 3) = 0000000000011000
Register value       = 0000000000011010 = 0x1A = 26
```

### 💡 Hints

- Shift each field to its bit position: `ENABLE` at bit 0, `MODE` at bit 1, `SPEED` at bit 3.
- Combine the fields with OR (`|`).
- Parenthesize macro parameters and the complete expression.
- The fields together cannot reach bits 6–7, so `RESERVED` stays `0` automatically when inputs stay in range.

### 💻 Solution

```c
#include <stdio.h>
#include <stdint.h>

// Define macros here
#define ENABLE(enable) enable
#define MODE(mode) (mode << 1)
#define SPEED(speed) (speed << 3)

uint16_t build_register(uint8_t enable, uint8_t mode, uint8_t speed) {
    // Use macros to set fields
    return ENABLE(enable) | MODE(mode) | SPEED(speed);
}

int main() {
    uint8_t enable, mode, speed;
    scanf("%hhu %hhu %hhu", &enable, &mode, &speed);

    uint16_t reg = build_register(enable, mode, speed);
    printf("%u", reg);
    return 0;
}
```
