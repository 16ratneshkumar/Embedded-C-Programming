# Problem 8: Compress Interleaved Bits (Reverse Bit Spreading)

### Problem Statement

An 8-bit value can be spread into a 16-bit value by inserting zero bits between its original bits. Write a **C program** to reverse that process.

The program must:

- Accept a 16-bit unsigned integer.
- Extract the bits at even-numbered positions: `0, 2, 4, 6, 8, 10, 12, 14`.
- Pack those bits into an 8-bit result in their original order.
- Print the reconstructed 8-bit value as an unsigned decimal integer.

Bit position 0 is the least significant bit. The extracted bits are packed so that the bit from input position 0 becomes output position 0, the bit from input position 2 becomes output position 1, and so on.

### Input Format

- One unsigned 16-bit decimal integer `val` in the range `0-65535`.

### Output Format

- The reconstructed 8-bit value as an unsigned decimal integer in the range `0-255`.

### Example 1 (Interleaved value)

#### Input

```
20548
```

#### Output

```
202
```

#### Explanation

```
20548 = 0101000001000100
Extract even-position bits and pack them:
         11001010 = 202
```

### Example 2 (All extracted bits set)

#### Input

```
21845
```

#### Output

```
255
```

#### Explanation

```
21845 = 0101010101010101
All positions 0, 2, 4, 6, 8, 10, 12, and 14 are set.
The reconstructed value is 11111111 = 255.
```

### Example 3 (Only the lowest bit set)

#### Input

```
1
```

#### Output

```
1
```

#### Explanation

```
1 = 0000000000000001
Input position 0 becomes output position 0, so the result is 00000001 = 1.
```

### Hints

- Keep only the even-position bits with an alternating-bit mask.
- Repeatedly combine neighboring groups with right shifts and masks.
- Use a 16-bit input type and return the packed result as an 8-bit value.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

uint8_t compress_bits(uint16_t val) {
    val = val & 0x55555555;             
    val = (val | (val >> 1)) & 0x33333333;
    val = (val | (val >> 2)) & 0x0F0F0F0F;
    val = (val | (val >> 4)) & 0x00FF00FF;
    return val;
}

int main() {
    uint16_t val;
    scanf("%hu", &val);

    uint8_t result = compress_bits(val);
    printf("%u", result);
    return 0;
}
```
