# Problem 7: Bit Reversal in an 8-bit Value

### Problem Statement

You are given an 8-bit unsigned integer. Your task is to reverse the order of its bits (position 0 becomes position 7, position 1 becomes position 6, and so on) and print the resulting 8-bit value as an unsigned decimal integer.

The program must:

- Accept one 8-bit unsigned integer `val` in the range `0-255`.
- Reverse all 8 bits of the value.
- Print the bit-reversed value as an unsigned decimal integer.

Bit position 0 is the least significant bit. Use pure bitwise logic only; do not use a lookup table or any standard library function.

### Input Format

- One unsigned 8-bit decimal integer `val` in the range `0-255`.

### Output Format

- The bit-reversed value as an unsigned decimal integer in the range `0-255`.

### Example 1 (Simple reversal)

#### Input

```
26
```

#### Output

```
88
```

#### Explanation

```
26 = 00011010
Reversed: 01011000 = 88
```

### Example 2 (Bits at both ends)

#### Input

```
176
```

#### Output

```
13
```

#### Explanation

```
176 = 10110000
Reversed: 00001101 = 13
```

### Example 3 (All bits set)

#### Input

```
255
```

#### Output

```
255
```

#### Explanation

```
255 = 11111111
Reversing all bits leaves the value unchanged, so the result is 255.
```

### Explanation

For each of the 8 bit positions, the loop shifts the running result left by one, copies the current least significant bit of `val` into it with a bitwise OR, and then shifts `val` right by one. After 8 iterations, the original bits appear in the result in the reverse order.

### Hints

- Loop exactly 8 times.
- In each iteration, shift the result left and OR in the input's least significant bit.
- Shift the input right by one bit each iteration to expose the next bit.
- Use an 8-bit unsigned type such as `uint8_t`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

uint8_t reverse_bits(uint8_t val) {
    uint8_t result = 0;
    for (int i=0;i<8;i++){
        result <<= 1 ;         
        result |= (val & 1) ;    
        val >>= 1 ;
    }
    return result;
}

int main() {
    uint8_t val;
    scanf("%hhu", &val);

    uint8_t result = reverse_bits(val);
    printf("%u", result);
    return 0;
}
```
