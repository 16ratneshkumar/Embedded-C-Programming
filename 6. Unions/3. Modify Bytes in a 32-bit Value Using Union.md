# Problem 3: Modify Bytes in a 32-bit Value Using Union

### Problem Statement

You are given a 32-bit integer stored in a union that also exposes its four individual bytes.

Your task is to:

- Use the union to modify the 2nd and 3rd bytes, that is `bytes[1]` and `bytes[2]`, with new values.
- Reconstruct and print the modified 32-bit value by reading the `value` member back.

Constraints:

- Use only union-based access. Do not use bitwise operations or shifts.
- Assume a little-endian machine, so `bytes[0]` is the least significant byte.

### Input Format

- Three unsigned integers separated by spaces:
  1. `value`, the original 32-bit value from `0` to `4294967295`.
  2. `new_b1`, the new value for `bytes[1]` from `0` to `255`.
  3. `new_b2`, the new value for `bytes[2]` from `0` to `255`.

### Output Format

- The modified 32-bit value as a decimal integer.

### Example 1 (Both bytes replaced)

#### Input

```
305419896 170 187
```

#### Output

```
314288760
```

### Example 2 (Only the low two bytes change)

#### Input

```
1 255 255
```

#### Output

```
16776961
```

### Example 3 (Value starts at zero)

#### Input

```
0 1 2
```

#### Output

```
131328
```

### Explanation

Both members share the same 4 bytes of storage, so writing `bytes[1]` and `bytes[2]` overwrites exactly those two positions of `value` and leaves the other two untouched.

```
Example 1: 0x12345678 = [0x78, 0x56, 0x34, 0x12]
           bytes[1] = 0xAA, bytes[2] = 0xBB
           result   = [0x78, 0xAA, 0xBB, 0x12] = 0x12BBAA78 = 314288760

Example 2: 0x00000001 = [0x01, 0x00, 0x00, 0x00]
           bytes[1] = 0xFF, bytes[2] = 0xFF
           result   = [0x01, 0xFF, 0xFF, 0x00] = 0x00FFFF01 = 16776961

Example 3: 0x00000000 = [0x00, 0x00, 0x00, 0x00]
           bytes[1] = 0x01, bytes[2] = 0x02
           result   = [0x00, 0x01, 0x02, 0x00] = 0x00020100 = 131328
```

### Hints

- Declare `typedef union { uint32_t value; uint8_t bytes[4]; } Register;`.
- Store the input into `reg.value` first, then assign the two new bytes.
- Print `reg.value`; no shifting or masking is needed to reassemble it.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

typedef union {
    uint32_t value;
    uint8_t bytes[4];
} Register;

// Write logic here using union to modify byte[1] and byte[2]
void modify_and_print(uint32_t input, uint8_t b1, uint8_t b2) {
    // Your logic here
    Register reg;
    reg.value = input;
    reg.bytes[1] = b1;
    reg.bytes[2] = b2;
    printf("%u", reg.value);
}

int main() {
    uint32_t num;
    uint8_t b1, b2;
    scanf("%u %hhu %hhu", &num, &b1, &b2);
    modify_and_print(num, b1, b2);
    return 0;
}
```
