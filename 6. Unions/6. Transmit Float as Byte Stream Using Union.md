# Problem 6: Transmit Float as Byte Stream Using Union

### Problem Statement

In embedded systems, floating-point values are often sent over UART or SPI as raw bytes. You are given a `float` value and must simulate how it would be serialized into 4 bytes.

Your task is to:

- Define a union holding a `float` and a `uint8_t[4]` byte array.
- Read a float from input.
- Use the union to print the four bytes in order, least significant byte first.

Constraints:

- Assume a 32-bit `float` in IEEE 754 format and a little-endian machine, so `bytes[0]` is the least significant byte of the mantissa.

### Input Format

- One floating-point value, for example `1.0` or `-2.5`.

### Output Format

- Four lines in this exact order, each formatted as `Byte <index>: <value>`:

```
Byte 0: <byte>
Byte 1: <byte>
Byte 2: <byte>
Byte 3: <byte>
```

### Example 1

#### Input

```
1.0
```

#### Output

```
Byte 0: 0
Byte 1: 0
Byte 2: 128
Byte 3: 63
```

### Example 2

#### Input

```
-2.5
```

#### Output

```
Byte 0: 0
Byte 1: 0
Byte 2: 32
Byte 3: 192
```

### Example 3

#### Input

```
0.0
```

#### Output

```
Byte 0: 0
Byte 1: 0
Byte 2: 0
Byte 3: 0
```

### Explanation

Both union members share the same 4 bytes of storage, so storing the float and then reading the array gives the raw representation split by byte position.

```
Example 1: 1.0  = 0x3F800000 -> [0x00, 0x00, 0x80, 0x3F] -> 0   0   128 63
Example 2: -2.5 = 0xC0200000 -> [0x00, 0x00, 0x20, 0xC0] -> 0   0    32 192
Example 3: 0.0  = 0x00000000 -> [0x00, 0x00, 0x00, 0x00] -> 0   0     0   0
```

### Hints

- Declare `typedef union { float f; uint8_t bytes[4]; } FloatPacket;`.
- Scan into a `float` variable first, then assign it to `ftpkt.f`.
- Loop over the four indices, printing a newline after every byte except the last.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

typedef union {
    float f;
    uint8_t bytes[4];
} FloatPacket;

int main() {
    float input;
    scanf("%f", &input);

    // Fill union and print 4 bytes
    FloatPacket ftpkt;
    ftpkt.f = input;
    for (uint8_t i = 0; i < 4; i++) {
        printf("Byte %u: %u", i, ftpkt.bytes[i]);
        if (i < 3) {
            printf("\n");
        }
    }
    return 0;
}
```
