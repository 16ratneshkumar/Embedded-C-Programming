# Problem 2: Union Extract Bytes from a 32-bit Value

### Problem Statement

Overlay a `uint32_t` value with a 4-byte `uint8_t` array inside a single union, then print the four bytes of that value in little-endian order, meaning least significant byte first.

Constraints:

- Use only union access. Do not use bit masking or shifts.
- Assume the program runs on a little-endian machine, where `bytes[0]` is the least significant byte.

### Input Format

- One unsigned 32-bit integer from `0` to `4294967295`.

### Output Format

- The four bytes separated by single spaces, least significant byte first.

### Example 1 (`0x12345678`)

#### Input

```
305419896
```

#### Output

```
120 86 52 18
```

### Example 2 (All bits set)

#### Input

```
4294967295
```

#### Output

```
255 255 255 255
```

### Example 3 (Only the least significant byte is set)

#### Input

```
1
```

#### Output

```
1 0 0 0
```

### Explanation

Both union members share the same 4 bytes of storage, so scanning into the integer member and then reading the array member gives the value already split by byte position.

```
305419896 = 0x12345678
bytes[0] = 0x78 = 120   (bits 0-7)
bytes[1] = 0x56 = 86    (bits 8-15)
bytes[2] = 0x34 = 52    (bits 16-23)
bytes[3] = 0x12 = 18    (bits 24-31)
```

### Hints

- Declare `typedef union { uint32_t value; uint8_t bytes[4]; } Value32;`.
- Scan the integer into the `value` member, then loop over `bytes[0]` to `bytes[3]`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

typedef union {
    uint32_t value;
    uint8_t bytes[4];
} Value32;

int main() {
    Value32 v;
    scanf("%" SCNu32, &v.value);

    for (int i = 0; i < 4; i++) {
        printf("%u", v.bytes[i]);
        if (i < 3) {
            printf(" ");
        }
    }

    return 0;
}
```
