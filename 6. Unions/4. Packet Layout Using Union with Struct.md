# Problem 4: Packet Layout Using Union with Struct

### Problem Statement

You are implementing a 6-byte communication packet for transmission. Each packet is laid out as:

| Field          | Size (bytes) |
|----------------|:------------:|
| Start Byte     | 1            |
| Command        | 1            |
| Data           | 2            |
| CRC            | 1            |
| End Byte       | 1            |

Your task is to:

- Define a union that overlays a struct view of these fields with a `uint8_t[6]` array view.
- Accept values for `start`, `command`, `data` (16-bit), `crc`, and `end`.
- Fill the packet through the struct members.
- Print the raw 6 bytes using the array view.

The struct is filled first and read back through the array, so the byte order comes from the machine's own layout. On a little-endian machine the low byte of `data` appears first.

### Input Format

- Five unsigned integers separated by spaces: `start` (`0`–`255`), `command` (`0`–`255`), `data` (`0`–`65535`), `crc` (`0`–`255`), `end` (`0`–`255`).

### Output Format

- The six raw bytes separated by single spaces, in memory order from index `0` to `5`.

### Example 1 (Mixed field values)

#### Input

```
165 1 4660 119 90
```

#### Output

```
165 1 52 18 119 90
```

### Example 2 (`data` is a single low byte)

#### Input

```
170 255 255 254 85
```

#### Output

```
170 255 255 0 254 85
```

### Example 3 (All fields zero except `end`)

#### Input

```
0 0 0 0 255
```

#### Output

```
0 0 0 0 0 255
```

### Explanation

Each struct field lines up with the packet layout, so writing the fields lays the bytes out in order. Reading the same memory through the array view exposes those bytes without a copy.

```
Example 1: start=165, command=1, data=4660 (0x1234), crc=119, end=90
           data is stored low byte first -> 0x34, 0x12
           raw = [165, 1, 52, 18, 119, 90]

Example 2: start=170, command=255, data=255 (0x00FF), crc=254, end=85
           data is stored low byte first -> 0xFF, 0x00
           raw = [170, 255, 255, 0, 254, 85]
```

### Hints

- Keep `uint8_t start` and `uint8_t command` before `uint16_t data` so the 2-byte field stays 2-byte aligned.
- Fill the fields through `pkt.fields.start`, `pkt.fields.command`, and so on.
- Loop over `pkt.raw[0]` to `pkt.raw[5]`, printing a space between bytes but not after the last one.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

typedef union {
    struct {
        uint8_t start;
        uint8_t command;
        uint16_t data;
        uint8_t crc;
        uint8_t end;
    } fields;
    uint8_t raw[6];
} Packet;

// Fill struct fields and print raw bytes
void build_and_print_packet(uint8_t s, uint8_t c, uint16_t d, uint8_t crc, uint8_t e) {
    // Your logic here
    Packet pkt;
    pkt.fields.start = s;
    pkt.fields.command = c;
    pkt.fields.data = d;
    pkt.fields.crc = crc;
    pkt.fields.end = e;

    for (uint8_t i = 0; i < 6; i++) {
        printf("%u", pkt.raw[i]);
        if (i < 5) {
            printf(" ");
        }
    }
}

int main() {
    uint8_t s, c, crc, e;
    uint16_t d;
    scanf("%hhu %hhu %hu %hhu %hhu", &s, &c, &d, &crc, &e);
    build_and_print_packet(s, c, d, crc, e);
    return 0;
}
```
