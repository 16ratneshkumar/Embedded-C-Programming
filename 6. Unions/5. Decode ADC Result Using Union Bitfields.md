# Problem 5: Decode ADC Result Using Union Bitfields

### Problem Statement

Many embedded microcontrollers store an ADC result in a packed format where the 12-bit conversion result and the channel number share one 16-bit register.

| Bits   | Field       | Description     |
|:------:|-------------|-----------------|
| 0–11   | `adc_value` | ADC result, `0`–`4095` |
| 12–15  | `channel`   | ADC channel, `0`–`15` |

Bit positions are zero-based, where bit 0 is the least significant bit.

Your task is to:

- Define a union that overlays a raw `uint16_t adc_reg` with a struct of `adc_value` (12 bits) and `channel` (4 bits).
- Read `adc_reg` from input.
- Print the channel number, then the ADC result.

### Input Format

- A hexadecimal value from `0000` to `FFFF`, written without the `0x` prefix, representing the raw ADC register.

### Output Format

- Two lines in this exact order:

```
Channel: <channel>
ADC Value: <adc_value>
```

### Example 1 (Channel 12)

#### Input

```
C3F5
```

#### Output

```
Channel: 12
ADC Value: 1013
```

### Example 2 (Channel 1)

#### Input

```
10FF
```

#### Output

```
Channel: 1
ADC Value: 255
```

### Example 3 (Channel 0, maximum result)

#### Input

```
0FFF
```

#### Output

```
Channel: 0
ADC Value: 4095
```

### Explanation

The bitfields split the 16 bits by position, so no shift or mask is needed to separate the two values.

```
Example 1: 0xC3F5 = 1100 0011 1111 0101
           channel   = upper 4 bits = 1100 = 12
           adc_value = lower 12 bits = 0011 1111 0101 = 0x3F5 = 1013

Example 2: 0x10FF = 0001 0000 1111 1111
           channel   = 0001 = 1
           adc_value = 0000 1111 1111 = 0x0FF = 255

Example 3: 0x0FFF = 0000 1111 1111 1111
           channel   = 0000 = 0
           adc_value = 1111 1111 1111 = 0xFFF = 4095
```

### Hints

- Use an anonymous struct inside the union so the bitfield members are reachable directly on the union object.
- Give the bitfields a `uint16_t` base type, for example `uint16_t adc_value : 12;`.
- Store the scanned input into `res.adc_reg`, then read `res.channel` and `res.adc_value`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

typedef union {
    struct {
        uint16_t adc_value : 12;
        uint16_t channel   : 4;
    };
    uint16_t adc_reg;
} ADC_Result;

int main() {
    uint16_t reg;
    scanf("%hx", &reg);

    // Fill union and print channel and adc_value
    ADC_Result res;
    res.adc_reg = reg;
    printf("Channel: %u\n", res.channel);
    printf("ADC Value: %u", res.adc_value);
    return 0;
}
```
