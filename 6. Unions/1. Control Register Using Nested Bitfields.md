# Problem 1: Control Register Using Nested Bitfields

### Problem Statement

You are given an 8-bit control register represented as a union of a raw byte and a nested struct of bitfields.

| Bits | Field      | Description                   |
|:----:|------------|-------------------------------|
| 0    | `enable`   | `1` = ON, `0` = OFF           |
| 1    | `mode`     | `0` = Normal, `1` = Sleep     |
| 2–3  | `priority` | 2-bit value (`0`–`3`)         |
| 4–7  | `reserved` | Reserved, must be `0`         |

Bit positions are zero-based, where bit 0 is the least significant bit.

Simulate the register with a union, then validate it through a pointer to that union:

- `enable` must be `1`.
- `priority` must be less than or equal to `2`.
- `reserved` must be all `0`.

Return `1` if the register is valid, otherwise return `0`.

### Input Format

- A hexadecimal value from `00` to `FF`, written without the `0x` prefix, representing the raw register value.

### Output Format

- `1` if the register passes all three checks, otherwise `0`.

### Example 1 (Valid register)

#### Input

```
05
```

#### Output

```
1
```

### Example 2 (Priority out of range)

#### Input

```
0F
```

#### Output

```
0
```

### Example 3 (Reserved bits are not zero)

#### Input

```
95
```

#### Output

```
0
```

### Explanation

Both union members start at the same address, so scanning into the raw byte and then reading the bitfield struct reinterprets the same 8 bits as named fields. Validation therefore needs no masks at all.

```
Example 1: 0x05 = 00000101 -> enable=1, mode=0, priority=01, reserved=0000 -> valid
Example 2: 0x0F = 00001111 -> enable=1, mode=1, priority=11 (3 > 2)       -> invalid
Example 3: 0x95 = 10010101 -> enable=1, mode=0, priority=01, reserved=1001 -> invalid
```

### Hints

- Declare a union with an `unsigned char` member and a struct of bitfields that adds up to exactly 8 bits.
- Reach the fields through the pointer with the `->` operator.
- Compare `reserved` directly against `0`; no mask is required.

### Solution

```c
#include <stdio.h>

typedef union {
    unsigned char reg;
    struct {
        unsigned char enable : 1;
        unsigned char mode : 1;
        unsigned char priority : 2;
        unsigned char reserved : 4;
    } bits;
} ControlRegister;

int validate_register(ControlRegister *ctrl) {
    if (ctrl->bits.enable != 1) return 0;
    if (ctrl->bits.priority > 2) return 0;
    if (ctrl->bits.reserved != 0) return 0;
    return 1;
}

int main() {
    ControlRegister ctrl;
    scanf("%hhx", &ctrl.reg);

    int result = validate_register(&ctrl);
    printf("%d", result);

    return 0;
}
```
