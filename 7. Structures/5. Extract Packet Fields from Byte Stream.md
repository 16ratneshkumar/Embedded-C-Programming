# Problem 5: Extract Packet Fields from Byte Stream

### Problem Statement

You receive a 6-byte data packet from a peripheral interface such as UART or I2C. The byte stream format is:

| Byte Index | Field     | Size (bytes) |
|:----------:|-----------|:------------:|
| 0          | `start`   | 1            |
| 1          | `command` | 1            |
| 2–3        | `data`    | 2            |
| 4          | `crc`     | 1            |
| 5          | `end`     | 1            |

The packet is given as an array `uint8_t buffer[6]`. Overlay a `Packet` struct on that buffer and print each field as an integer.

### Input Format

- Six unsigned 8-bit integers (`0`–`255`), one per byte, in stream order: `start`, `command`, the two `data` bytes, `crc`, `end`.

### Output Format

- Five lines in this exact order:

```
Start: <start>
Command: <command>
Data: <data>
CRC: <crc>
End: <end>
```

### Example 1 (Typical packet)

#### Input

```
165 1 52 18 119 90
```

#### Output

```
Start: 165
Command: 1
Data: 4660
CRC: 119
End: 90
```

### Example 2 (Maximum payload bytes)

#### Input

```
170 255 255 0 254 85
```

#### Output

```
Start: 170
Command: 255
Data: 255
CRC: 254
End: 85
```

### Explanation

The struct's field order and sizes match the stream layout exactly, so casting the buffer to a `Packet *` makes each field readable at its byte offset. The two `data` bytes are read together as a `uint16_t` in the host's byte order, so on a little-endian machine the first byte is the low byte.

```
Example 1: buffer = [165, 1, 52, 18, 119, 90]
          start   = buffer[0] = 165
          command = buffer[1] = 1
          data    = buffer[2] | (buffer[3] << 8) = 52 + 18*256 = 4660
          crc     = buffer[4] = 119
          end     = buffer[5] = 90

Example 2: buffer = [170, 255, 255, 0, 254, 85]
          data    = 255 + 0*256 = 255
```

### Hints

- Declare the struct with `uint8_t`, `uint8_t`, `uint16_t`, `uint8_t`, `uint8_t` in that order.
- Cast the buffer with `(Packet *) buffer` and read the fields through `->`.
- Read all six values with `scanf("%hhu", ...)` into a `uint8_t` array.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

typedef struct {
    uint8_t start;
    uint8_t command;
    uint16_t data;
    uint8_t crc;
    uint8_t end;
} Packet;

void print_packet_fields(uint8_t *buffer) {
    // Overlay struct and print values
    Packet *packet = (Packet *) buffer;
    printf("Start: %d\n", packet->start);
    printf("Command: %d\n", packet->command);
    printf("Data: %d\n", packet->data);
    printf("CRC: %d\n", packet->crc);
    printf("End: %d\n", packet->end);
}

int main() {
    uint8_t buffer[6];
    for (int i = 0; i < 6; i++) {
        scanf("%hhu", &buffer[i]);
    }
    print_packet_fields(buffer);
    return 0;
}
```
