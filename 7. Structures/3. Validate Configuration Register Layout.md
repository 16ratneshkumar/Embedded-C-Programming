# Problem 3: Validate Configuration Register Layout

### Problem Statement

You are given a `ConfigRegister` struct that simulates a 16-bit configuration register. Every bit of the register has a specific meaning.

| Bit Position | Meaning                                                             |
|:------------:|---------------------------------------------------------------------|
| 0            | Enable (`1` = ON)                                                   |
| 1            | Mode (`0` = Normal, `1` = Safe)                                     |
| 2–3          | Priority (`00` = Low, `01` = Medium, `10` = High, `11` = Invalid)   |
| 4–15         | Reserved, must be `0`                                               |

Bit positions are zero-based, where bit 0 is the least significant bit.

Validate the register by reading it through a pointer:

- Return `1` if bit 0 is set (Enable ON).
- Return `1` if bits 2–3 hold a valid priority, that is not `11`.
- Return `1` if all bits 4–15 are `0`.
- Return `0` otherwise.

### Input Format

- A hexadecimal value from `0000` to `FFFF`, written without the `0x` prefix, representing the raw register value.

### Output Format

- `1` if the register is valid, otherwise `0`.

### Example 1 (Valid register)

#### Input

```
0005
```

#### Output

```
1
```

### Example 2 (High priority is still valid)

#### Input

```
000B
```

#### Output

```
1
```

### Example 3 (Reserved bit is set)

#### Input

```
0015
```

#### Output

```
0
```

### Explanation

Each check maps to one bit range, so the register can be validated with a bit test instead of a struct of bitfields.

```
Example 1: 0x0005 = 0000000000000101 -> Enable=1, Mode=0, Priority=01 (Medium), Reserved=0 -> valid
Example 2: 0x000B = 0000000000001011 -> Enable=1, Mode=1, Priority=10 (High),   Reserved=0 -> valid
Example 3: 0x0015 = 0000000000010101 -> Enable=1, Mode=0, Priority=01 (Medium), Bit 4 set -> invalid
```

### Hints

- Copy the register out of the struct first, for example `cfg->reg`.
- Test bit 0 with `reg & 0x0001`.
- Extract bits 2–3 with `(reg >> 2) & 0x03`.
- Detect any reserved bit with `reg & 0xFFF0`.

### Solution

```c
#include <stdio.h>

typedef struct {
    unsigned short reg;
} ConfigRegister;

int validate_config(ConfigRegister *cfg) {
    // Write logic using pointer access
    unsigned short regValue = cfg->reg;

    if ((regValue & 0x0001) == 0) return 0;
    unsigned short priority = (regValue >> 2) & 0x03;
    if (priority == 0x03) return 0;
    if (regValue & 0xFFF0) return 0;
    return 1;
}

int main() {
    ConfigRegister cfg;
    scanf("%hx", &cfg.reg);

    int result = validate_config(&cfg);
    printf("%d", result);

    return 0;
}
```
