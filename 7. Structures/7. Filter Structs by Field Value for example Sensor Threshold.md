# Problem 7: Filter Structs by Field Value (Sensor Threshold)

### Problem Statement

In real embedded systems you often store device status or sensor data in arrays of structs. You may need to filter only the relevant records based on one field, for example sensors reading above a certain threshold.

Each record contains:

| Field            | Type        | Description                    |
|------------------|-------------|--------------------------------|
| `name`           | `char[10]`  | Sensor identifier              |
| `value`          | `uint8_t`   | Reading from `0` to `255`      |

Your task is to:

- Read `n` sensor records, each a name and a value.
- Print only the records whose `value` is greater than or equal to `threshold`, in input order.

### Input Format

- `n`, the number of sensor records, from `1` to `100`.
- `threshold`, an unsigned 8-bit integer from `0` to `255`.
- Then `n` lines, each containing a name of at most 9 characters followed by a value from `0` to `255`.

### Output Format

- One line per matching record, formatted as `name value`.
- Nothing is printed when no record meets the threshold.

### Example 1 (Mixed readings)

#### Input

```
4 50
T1 45
T2 67
T3 10
T4 90
```

#### Output

```
T2 67
T4 90
```

### Example 2 (Boundary at the threshold)

#### Input

```
3 100
A1 99
A2 100
A3 101
```

#### Output

```
A2 100
A3 101
```

### Example 3 (No record matches)

#### Input

```
2 200
S1 10
S2 20
```

#### Output

```
(nothing)
```

### Explanation

The comparison is inclusive, so a record whose value equals the threshold is printed. Iteration stops at `n`, and records are visited in the order they were read, so the output keeps the input order.

```
Example 1: threshold = 50
           T1 45  -> 45 >= 50 is false, skipped
           T2 67  -> 67 >= 50 is true,  printed
           T3 10  -> 10 >= 50 is false, skipped
           T4 90  -> 90 >= 50 is true,  printed

Example 2: threshold = 100
           A1 99  -> skipped,  A2 100 -> printed, A3 101 -> printed
```

### Hints

- Read the name and the value with `scanf("%s %hhu", sensors[i].name, &sensors[i].value)`.
- Leave `name` as the first member so the `char[10]` slot is large enough for the identifier.
- The array holds at most 100 records.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

struct Sensor {
    char name[10];
    uint8_t value;
};

void print_above_threshold(struct Sensor sensors[], uint8_t n, uint8_t threshold) {
    // Your logic here
    for (uint8_t i = 0; i < n; i++) {
        if (threshold <= sensors[i].value) {
            printf("%s %u\n", sensors[i].name, sensors[i].value);
        }
    }
}

int main() {
    uint8_t n, threshold;
    scanf("%hhu %hhu", &n, &threshold);

    struct Sensor sensors[100];
    for (uint8_t i = 0; i < n; i++) {
        scanf("%s %hhu", sensors[i].name, &sensors[i].value);
    }

    print_above_threshold(sensors, n, threshold);
    return 0;
}
```
