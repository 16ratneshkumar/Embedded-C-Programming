# Problem 4: Struct Padding

### Problem Statement

You are given a struct with the following fields, declared in this order:

```c
char a;
int b;
short c;
```

Your task is to:

- Declare a variable of this struct.
- Compute the offset in bytes of each field from the base address of the struct, that is from `&s`.
- Print the offset of `a`, the offset of `b`, the offset of `c`, and the total size of the struct.

The compiler inserts padding so that each field lands on an address that is a multiple of its own size. That padding is what makes the offsets and the total size larger than the sum of the field sizes.

### Input Format

- No input. The program prints the computed layout directly.

### Output Format

- Four lines in this exact order:

```
Offset of a: <offset>
Offset of b: <offset>
Offset of c: <offset>
Size: <size>
```

### Example 1 (Typical layout with a 4-byte `int`)

#### Input

```
(no input)
```

#### Output

```
Offset of a: 0
Offset of b: 4
Offset of c: 8
Size: 12
```

### Explanation

`a` sits at offset 0. The next free byte is offset 1, but an `int` needs 4-byte alignment, so 3 padding bytes are inserted and `b` starts at offset 4. `c` then follows `b` at offset 8, and the struct is padded up to a multiple of its 4-byte alignment, giving a total size of 12.

```
a  -> offset 0, size 1, next free 1
b  -> needs 4-byte alignment, 3 padding bytes, offset 4, size 4, next free 8
c  -> 2-byte alignment already satisfied, offset 8, size 2, next free 10
tail padding -> 2 bytes so the size is a multiple of 4, total 12
```

The exact numbers depend on the platform's alignment rules, which is why they are computed at runtime rather than hard-coded.

### Hints

- `offsetof(Type, member)` from `<stddef.h>` returns the offset of a member in bytes.
- `sizeof(Type)` returns the total size in bytes including padding.
- Both results have type `size_t`, so print them with a `size_t` compatible format specifier.

### Solution

```c
#include <stdio.h>
#include <stddef.h>

typedef struct {
    char a;
    int b;
    short c;
} MyStruct;

void print_offsets() {
    printf("Offset of a: %lu\n", offsetof(MyStruct, a));
    printf("Offset of b: %lu\n", offsetof(MyStruct, b));
    printf("Offset of c: %lu\n", offsetof(MyStruct, c));
    printf("Size: %lu", sizeof(MyStruct));
}

int main() {
    print_offsets();
    return 0;
}
```
