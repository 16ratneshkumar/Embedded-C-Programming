# Problem 6: Register Bitfields Using Struct Overlay

### Problem Statement

You are implementing a simulated 8-bit control register where each bit controls a feature. Rather than using masks, you will use a bitfield struct to access individual bits.

| Bit  | Field       | Size (bits) |
|:----:|-------------|:-----------:|
| 0    | `enable`    | 1           |
| 1–2  | `mode`      | 2           |
| 3    | `interrupt` | 1           |
| 4–7  | `reserved`  | 4           |

Bit positions are zero-based, where bit 0 is the least significant bit.

Your task is to:

- Define a union that overlays a struct of bitfields (`enable`, `mode`, `interrupt`, `reserved`) with a raw `uint8_t` register.
- Read `enable`, `mode`, and `interrupt` from input.
- Build the register by assigning to the bitfields, then print the final register as an 8-bit unsigned value.

Assumptions:

- `enable` is `0` or `1`.
- `mode` ranges from `0` to `3`.
- `interrupt` is `0` or `1`.

### Input Format

- Three unsigned 8-bit integers separated by spaces: `enable`, `mode`, `interrupt`.

### Output Format

- The resulting register value as a decimal integer from `0` to `255`.

### Example 1 (All fields non-zero)

#### Input

```
1 2 1
```

#### Output

```
13
```

### Example 2 (Only interrupt is set)

#### Input

```
0 0 1
```

#### Output

```
8
```

### Example 3 (Nothing is set)

#### Input

```
0 0 0
```

#### Output

```
0
```

### Explanation

The union lets you write named fields and read the same storage as a plain byte. The bitfield allocation unit places `enable` at bit 0, `mode` at bits 1–2, `interrupt` at bit 3, and `reserved` at bits 4–7.

```
Example 1: enable=1, mode=2, interrupt=1
           1       10       1        0000
           00001101 = 13

Example 2: enable=0, mode=0, interrupt=1
           0       00       1        0000
           00001000 = 8

Example 3: 00000000 = 0
```

### Hints

- Zero-initialize the union before assigning, for example `ControlRegister reg = {0};`.
- Read the three inputs as `uint8_t` with `scanf("%hhu %hhu %hhu", ...)`.
- Assign to `reg.bits.enable`, `reg.bits.mode`, and `reg.bits.interrupt`, then print `reg.reg`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

typedef union {
    struct {
        uint8_t enable    : 1;
        uint8_t mode      : 2;
        uint8_t interrupt : 1;
        uint8_t reserved  : 4;
    } bits;
    uint8_t reg;
} ControlRegister;

int main() {
    uint8_t e, m, i;
    scanf("%hhu %hhu %hhu", &e, &m, &i);

    // Construct and print register value
    ControlRegister ctrlReg = {0};
    ctrlReg.bits.enable = e;
    ctrlReg.bits.mode = m;
    ctrlReg.bits.interrupt = i;

    printf("%u", ctrlReg.reg);
    return 0;
}
```
