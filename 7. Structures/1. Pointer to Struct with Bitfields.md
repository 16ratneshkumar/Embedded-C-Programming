# 🧩 Problem 1: Pointer to Struct with Bitfields

### 📝 Problem Statement

You are given a pointer to a `UART_ControlRegister` struct representing a 32-bit hardware register.

The struct has the following bitfields:

```c
struct UART_ControlRegister {
    unsigned int baudrate : 4;   // Bits 0-3
    unsigned int tx_enable : 1;  // Bit 4
    unsigned int rx_enable : 1;  // Bit 5
    unsigned int tx_irq_en : 1;  // Bit 6
    unsigned int rx_irq_en : 1;  // Bit 7
    unsigned int parity_en : 1;  // Bit 8
    unsigned int stop_bits : 1;  // Bit 9
    unsigned int reserved : 22;  // Bits 10-31
};
```

Write a function that receives a pointer to this struct and configures the UART register as follows:

| Field | Value | Bit position |
| ----- | :---: | ------------ |
| `baudrate` | 9 | Bits 0–3 |
| `tx_enable` | 1 | Bit 4 |
| `rx_enable` | 1 | Bit 5 |
| `tx_irq_en` | 1 | Bit 6 |
| `rx_irq_en` | 0 | Bit 7 |
| `parity_en` | 1 | Bit 8 |
| `stop_bits` | 0 | Bit 9 |

Then print each field's value after configuration.

Bit position 0 is the least significant bit of the 32-bit register.

---

### 🧾 Input Format

This challenge has **no runtime input**. The configuration values above are compile-time
constants written by `configure_uart()`.

---

### 📤 Output Format

- Seven lines, one per field, in the order `baudrate`, `tx_enable`, `rx_enable`,
  `tx_irq_en`, `rx_irq_en`, `parity_en`, `stop_bits`.
- Each line has the form `field_name = value`, with no trailing text.

---

### ✅ Example 1 (All bits fit their declared width)

#### Output

```
baudrate = 9
tx_enable = 1
rx_enable = 1
tx_irq_en = 1
rx_irq_en = 0
parity_en = 1
stop_bits = 0
```

#### 🔍 Explanation

```
stop_bits (bit 9)  = 0
parity_en (bit 8)  = 1
rx_irq_en (bit 7)  = 0
tx_irq_en (bit 6)  = 1
rx_enable (bit 5)  = 1
tx_enable (bit 4)  = 1
baudrate (bits 0-3) = 1001 = 9

Register = 0000 0000 0000 0000 0000 0001 0111 1001 = 0x00000179
```

---

### 💡 Hints

- Bitfield members are reached through the pointer with `->`, exactly like ordinary
  struct members: `reg->baudrate = 9;`
- You never need masks or shifts — the compiler derives the shift and mask from the
  declared widths.
- Only the seven listed fields are written, so start from a zero-initialised struct
  (`= {0}`) to keep `reserved` at `0`.
- Bitfields declared as `unsigned int` promote to `int` when read, so `%u` prints them
  correctly.

---

### 💻 Solution

```c
#include <stdio.h>

struct UART_ControlRegister {
    unsigned int baudrate : 4;
    unsigned int tx_enable : 1;
    unsigned int rx_enable : 1;
    unsigned int tx_irq_en : 1;
    unsigned int rx_irq_en : 1;
    unsigned int parity_en : 1;
    unsigned int stop_bits : 1;
    unsigned int reserved : 22;
};

void configure_uart(struct UART_ControlRegister *reg) {
    reg->baudrate = 9;
    reg->tx_enable = 1;
    reg->rx_enable = 1;
    reg->tx_irq_en = 1;
    reg->rx_irq_en = 0;
    reg->parity_en = 1;
    reg->stop_bits = 0;
}

int main() {
    struct UART_ControlRegister reg = {0};

    configure_uart(&reg);

    printf("baudrate = %u\n", reg.baudrate);
    printf("tx_enable = %u\n", reg.tx_enable);
    printf("rx_enable = %u\n", reg.rx_enable);
    printf("tx_irq_en = %u\n", reg.tx_irq_en);
    printf("rx_irq_en = %u\n", reg.rx_irq_en);
    printf("parity_en = %u\n", reg.parity_en);
    printf("stop_bits = %u", reg.stop_bits);

    return 0;
}
```
