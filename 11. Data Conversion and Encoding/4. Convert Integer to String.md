# Problem 4: Convert Integer to String

### Problem Statement

In embedded systems, numeric values frequently need to be converted into a printable string format (e.g., for UART transmission or display output) without relying on standard C library functions like `itoa()` or `sprintf()`.

Write a C program that reads a signed 32-bit integer, converts it into its string representation, and prints each character separated by a single space.

You must not use `itoa()`, `sprintf()`, `snprintf()`, or standard string conversion libraries.

### Input Format

- A single signed 32-bit integer `n` (`-2147483648` to `2147483647`).

### Output Format

- The characters of the converted string representation printed with a single space between each character.

### Example 1 (Positive integer)

#### Input

```
123
```

#### Output

```
1 2 3
```

### Example 2 (Negative integer)

#### Input

```
-45
```

#### Output

```
- 4 5
```

### Example 3 (Zero)

#### Input

```
0
```

#### Output

```
0
```

### Explanation

To convert a signed integer to a spaced string representation:

1. **Zero Check**: If `n == 0`, output `0`.
2. **Sign Handling**: If `n < 0`, print `- ` and convert the magnitude to an unsigned type to safely handle `-2147483648` without signed integer overflow.
3. **Extract Digits**: Repeatedly take `rem = magnitude % 10` and `magnitude = magnitude / 10`.
4. **Order and Spacing**: Since digits are extracted from least significant to most significant, store them in a temporary buffer, then print them in reverse order, inserting a space between each character.

```
Example 1: 123
123 % 10 = 3
 12 % 10 = 2
  1 % 10 = 1
Digits in order: 1, 2, 3
Output: 1 2 3

Example 2: -45
Negative sign detected: '- '
 45 % 10 = 5
  4 % 10 = 4
Digits in order: 4, 5
Output: - 4 5
```

### Hints

- Use `uint32_t` or `unsigned int` for the absolute value to handle `INT32_MIN` safely.
- Extract individual digits using `% 10` and shift using `/ 10`.
- Store extracted characters in a buffer array and print in reverse order, placing spaces appropriately.

### Solution

```c
#include <stdio.h>

void print_integer_as_string(int num) {
    // Your logic here
    if (num == 0) {
        printf("0");
        return;
    }
    int i = 0;
    char res[10];
    if (num < 0){
        printf("- ");
        num = -1*num;
    };
    while (num){
        if (num >= 0){
            res[i++] = num % 10 + '0';
            num/=10;
        }
    }
    for (int j = i-1;j>=0;j--){
        printf("%c ", res[j]);
    }
}

int main() {
    int num;
    scanf("%d", &num);
    print_integer_as_string(num);
    return 0;
}
```
