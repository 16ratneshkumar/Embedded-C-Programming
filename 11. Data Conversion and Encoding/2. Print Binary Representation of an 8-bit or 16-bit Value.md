# Problem 2: Print Binary Representation of an 8-bit or 16-bit Value

### Problem Statement

In embedded development, visualizing the binary form of a value is crucial for debugging and understanding register configuration.

Write a C program that reads an unsigned integer (8-bit or 16-bit) and prints its binary representation, padded with leading zeros. The output must be 8 bits when the input is `255` or less, and 16 bits otherwise.

### Input Format

- One unsigned 16-bit integer (`uint16_t`), from `0` to `65535`.

### Output Format

- The binary representation padded with leading zeros: 8 bits when the value is `255` or less, otherwise 16 bits.

### Example 1 (8-bit value)

#### Input

```
10
```

#### Output

```
00001010
```

### Example 2 (8-bit boundary)

#### Input

```
255
```

#### Output

```
11111111
```

### Example 3 (16-bit value)

#### Input

```
1023
```

#### Output

```
0000001111111111
```

### Example 4 (16-bit boundary)

#### Input

```
65535
```

#### Output

```
1111111111111111
```

### Explanation

The number of bits is chosen from the value: `8` bits for values up to `255`, otherwise `16` bits. Each bit is tested from the most significant position down to bit `0`.

```
10    = 0x000A -> 00001010
255   = 0x00FF -> 11111111
1023  = 0x03FF -> 0000001111111111
65535 = 0xFFFF -> 1111111111111111
```

### Hints

- Decide the width with `int bits = (val <= 0xFF) ? 8 : 16;`.
- Loop from `bits - 1` down to `0` and test `val & (1 << i)`.
- Use `putchar()` to print one character per bit.

### Solution 1

```c
#include <stdio.h>
#include <stdint.h>

void print_binary(uint16_t val) {
    // Your logic here
    if (val > 255){
        for (int i=0;i<16;i++){
            if (val & 0x8000){
                val = val<<1;
                printf("%d",1);
            } else {
                val = val<<1;
                printf("%d",0);
            }
        }
    } else {
        for (int i=0;i<8;i++){
            if (val & 0x80){
                val = val<<1;
                printf("%d",1);
            } else {
                val = val<<1;
                printf("%d",0);
            }
        }
    }
}

int main() {
    uint16_t val;
    scanf("%hu", &val);
    print_binary(val);
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>
#include <stdint.h>

// Print 8-bit or 16-bit binary with leading 0s
void print_binary(uint16_t val) {
    int bits = (val <= 0xFF) ? 8 : 16;


    for (int i = bits - 1; i >= 0; i--) {
        putchar((val & (1 << i)) ? '1' : '0');
    }
}

int main() {
    uint16_t val;
    scanf("%hu", &val);
    print_binary(val);
    return 0;
}
```
