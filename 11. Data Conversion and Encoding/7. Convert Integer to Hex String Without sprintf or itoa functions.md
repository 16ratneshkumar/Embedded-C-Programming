# Problem 7: Convert Integer to Hex String Without sprintf or itoa Functions

### Problem Statement

In embedded systems, you may need to transmit an integer value as a hexadecimal string over UART, log output, or display drivers without linking heavy standard library functions like `sprintf()` or `itoa()`.

Write a C program that reads an unsigned 16-bit integer `num` and prints its hexadecimal string representation in uppercase without leading zeros (except for the value `0` which outputs `"0"`).

You must not use `itoa()`, `sprintf()`, `snprintf()`, or other built-in conversion functions.

### Input Format

- An unsigned 16-bit integer `num` (`0` to `65535`).

### Output Format

- The hexadecimal string representation in uppercase (`0`–`9`, `A`–`F`).

### Example 1 (8-bit max)

#### Input

```
255
```

#### Output

```
FF
```

### Example 2 (12-bit value)

#### Input

```
4095
```

#### Output

```
FFF
```

### Example 3 (Zero)

#### Input

```
0
```

#### Output

```
0
```

### Example 4 (Arbitrary value)

#### Input

```
4660
```

#### Output

```
1234
```

### Explanation

To convert an unsigned 16-bit integer to an uppercase hexadecimal string:

1. **Zero Check**: If `num == 0`, output `"0"`.
2. **Nibble Extraction**: Repeatedly extract the lowest 4 bits using `rem = num % 16` (or `num & 0x0F`), then shift right with `num = num / 16` (or `num >>= 4`).
3. **Character Mapping**:
   - If `rem < 10`, map to `'0' + rem`.
   - If `rem >= 10`, map to `'A' + (rem - 10)`.
4. **Reverse**: Since digits are extracted from least significant to most significant, store them in a buffer and reverse or print from the most significant digit.

```
Example 1: num = 255
255 % 16 = 15 ('F')
 15 % 16 = 15 ('F')
Reversed: FF

Example 4: num = 4660
4660 % 16 = 4 ('4')
 291 % 16 = 3 ('3')
  18 % 16 = 2 ('2')
   1 % 16 = 1 ('1')
Reversed: 1234
```

### Hints

- Extract each hexadecimal digit using `rem = num & 0x0F` or `rem = num % 16`.
- Map digits to `'0' + rem` for values `< 10` and `'A' + (rem - 10)` for values `>= 10`.
- Store characters into a buffer and output them in reverse order.
- Handle `num == 0` as a special case.

### Solution 1

```c
#include <stdio.h>
#include <stdint.h>

void print_hex(uint16_t num) {
    // Your logic here
    if (num == 0) {
        printf("0");
        return;
    }
    char hex[6];
    int i = 0;
    while (num){
        if (num >= 0){
            hex[i++] = num % 16;
            if (hex[i-1] >= 10){
                hex[i-1] += ('A' - 10);
            } else{
                hex[i-1] += '0';
            }
            num/=16;
        }
   }
    for (int j = i-1;j>=0;j--){
        printf("%c", hex[j]);
    }
}

int main() {
    uint16_t num;
    scanf("%hu", &num);
    print_hex(num);
    return 0;
}
```

### Solution 2

```c
#include <stdio.h>
#include <stdint.h>

// Convert number to hex string manually and print it
void print_hex(uint16_t num) {
    if (num == 0) {
        printf("0");
        return;
    }

    char hex_digits[] = "0123456789ABCDEF";
    char buffer[5];  // max 4 hex digits + '\0'
    int i = 0;

    while (num > 0) {
        buffer[i++] = hex_digits[num % 16];
        num /= 16;
    }

    // Print in reverse order
    for (int j = i - 1; j >= 0; j--) {
        putchar(buffer[j]);
    }
}

int main() {
    uint16_t num;
    scanf("%hu", &num);
    print_hex(num);
    return 0;
}
```
