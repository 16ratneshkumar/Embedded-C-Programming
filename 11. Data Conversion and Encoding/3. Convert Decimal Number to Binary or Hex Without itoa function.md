# Problem 3: Convert Decimal Number to Binary or Hex Without itoa Function

### Problem Statement

In firmware development, numeric values frequently need to be converted to binary or hexadecimal strings manually — for instance, sending over UART or displaying on an LCD — without using standard library functions like `itoa()` or `sprintf()`.

Write a C program that reads an unsigned integer `num` and a target `base` (`2` or `16`), and prints the number converted to the specified base as a string.

You must not use any standard library string conversion functions such as `itoa()`, `sprintf()`, or `snprintf()`. Use only loops and arithmetic operations.

### Input Format

- Two space-separated integers:
  - An unsigned 32-bit integer `num` (`0` to `4294967295`).
  - An integer `base` (`2` or `16`).

### Output Format

- The string representation of the number in the specified base (using uppercase letters `A`–`F` for base 16).

### Example 1 (num = 10, base = 2)

#### Input

```
10 2
```

#### Output

```
1010
```

### Example 2 (num = 255, base = 16)

#### Input

```
255 16
```

#### Output

```
FF
```

### Example 3 (num = 0, base = 2)

#### Input

```
0 2
```

#### Output

```
0
```

### Explanation

To convert an unsigned integer to a string in a given base without library functions:

1. **Zero Check**: If `num` is `0`, output `"0"` immediately.
2. **Remainder & Division**: Repeatedly take `rem = num % base` to find the least significant digit, then update `num = num / base`.
3. **Character Mapping**:
   - If `rem < 10`, map to ASCII: `'0' + rem`.
   - If `rem >= 10`, map to uppercase hexadecimal ASCII: `'A' + (rem - 10)`.
4. **Reverse**: Digits are obtained from least significant to most significant, so reverse the accumulated buffer to get the final string.

```
Example 1: num = 10, base = 2
10 % 2 = 0, 10 / 2 = 5
 5 % 2 = 1,  5 / 2 = 2
 2 % 2 = 0,  2 / 2 = 1
 1 % 2 = 1,  1 / 2 = 0
Reversed characters: 1010

Example 2: num = 255, base = 16
255 % 16 = 15 ('F'), 255 / 16 = 15
 15 % 16 = 15 ('F'),  15 / 16 = 0
Reversed characters: FF
```

### Hints

- Use modulo (`% base`) to extract each digit and division (`/ base`) to shift to the next digit.
- Map remainder `rem < 10` using `'0' + rem` and `rem >= 10` using `'A' + (rem - 10)`.
- Accumulate the extracted digits into a temporary buffer and reverse them to print most significant digit first.
- Handle `num == 0` separately to ensure `'0'` is generated.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

void print_base(uint16_t num, uint8_t base) {
    // Your logic here
    char res[10];
    int i = 0;
    if (num == 0) printf("0");
    while (num != 0){
        uint8_t rem = num%base;
        res[i] = ((9 <= rem) ? (rem-10) +'A':rem + '0');
        num/=base;
        i++;
    }
    res[i] = '\0';
    for (int j = i; j >=0; j--){
        printf("%c", res[j]);
    }    
}

int main() {
    uint16_t num;
    uint8_t base;
    scanf("%hu %hhu", &num, &base);

    print_base(num, base);
    return 0;
}
```
