# Problem 1: Little Endian to Big Endian

### Problem Statement

In embedded systems, communication between processors may require byte-order conversion. You are given a 32-bit unsigned integer stored in little-endian format.

Write a C program to convert this value to big-endian by swapping its bytes, and print the result.

### Input Format

- One unsigned 32-bit integer in decimal, from `0` to `4294967295`.

### Output Format

- The byte-swapped 32-bit value printed in decimal.

### Example 1 (0x12345678)

#### Input

```
305419896
```

#### Output

```
2018915346
```

### Example 2 (0x00000001)

#### Input

```
1
```

#### Output

```
16777216
```

### Example 3 (0xAABBCCDD)

#### Input

```
2864434397
```

#### Output

```
3721182122
```

### Explanation

A 32-bit value has four bytes. Converting between little-endian and big-endian reverses their order.

```
Example 1: 0x12345678 -> 0x78563412 = 2018915346
Example 2: 0x00000001 -> 0x01000000 = 16777216
Example 3: 0xAABBCCDD -> 0xDDCCBBAA = 3721182122
```

### Hints

- Shift each byte into its new position with `<<` and mask it with `&`.
- Combine the shifted bytes with bitwise OR (`|`).
- A union of a 32-bit integer and a byte array is an alternative way to see the byte order.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

uint32_t convert_endian(uint32_t value) {
    // Write logic to swap bytes
    uint32_t reg = 0;
    reg = ((value << 24) & 0xff000000)|(value >> 8 & 0x0000ff00)|(value << 8 & 0x00ff0000)|(value >> 24 & 0x000000ff);
    return reg;
}

int main() {
    uint32_t val;
    scanf("%u", &val);
    printf("%u", convert_endian(val));
    return 0;
}
```
