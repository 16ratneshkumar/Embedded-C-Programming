# Problem 6: Convert Hexadecimal String to Integer Without strtol or sscanf Functions

### Problem Statement

In embedded systems, hexadecimal strings are frequently received from serial terminals, packet headers, or config files (such as `"1A3F"` or `"af"`). These strings must be converted into numeric integers without using standard library functions like `strtol()` or `sscanf()`.

Write a C program that reads a hexadecimal string of up to 4 characters (representing an unsigned 16-bit integer) and converts it into a `uint16_t` value. The program must handle both uppercase (`'A'`–`'F'`) and lowercase (`'a'`–`'f'`) hexadecimal characters.

You must not use `strtol()`, `sscanf()`, `atoi()`, or other library conversion functions.

### Input Format

- A single null-terminated hexadecimal string of up to 4 characters (`0`–`9`, `a`–`f`, `A`–`F`).

### Output Format

- The converted unsigned 16-bit integer printed in decimal.

### Example 1 (Mixed-case hex)

#### Input

```
1A3F
```

#### Output

```
6719
```

### Example 2 (Uppercase 2-digit)

#### Input

```
AF
```

#### Output

```
175
```

### Example 3 (Zero with leading zeros)

#### Input

```
0000
```

#### Output

```
0
```

### Example 4 (Lowercase maximum 16-bit)

#### Input

```
ffff
```

#### Output

```
65535
```

### Explanation

Each hexadecimal character represents 4 bits (a nibble):

1. Initialize `val = 0`.
2. For each character `c` until `\0`:
   - If `c >= '0' && c <= '9'`, numeric value is `c - '0'`.
   - If `c >= 'A' && c <= 'F'`, numeric value is `c - 'A' + 10`.
   - If `c >= 'a' && c <= 'f'`, numeric value is `c - 'a' + 10`.
3. Shift the accumulated value left by 4 bits (`val <<= 4`) and bitwise OR with the nibble value (`val |= digit`).
4. Print the final accumulator in decimal.

```
Example 1: "1A3F"
'1' -> digit = 1  -> val = 0x0001 = 1
'A' -> digit = 10 -> val = 0x001A = 26
'3' -> digit = 3  -> val = 0x01A3 = 419
'F' -> digit = 15 -> val = 0x1A3F = 6719
```

### Hints

- Loop over the string character by character until `\0`.
- Shift the accumulator left by 4 bits (`val = (val << 4) | digit`) for each hex digit.
- Support `'0'`–`'9'`, `'A'`–`'F'`, and `'a'`–`'f'` using conditional checks.

### Solution 1

```c
#include <stdio.h>
#include <stdint.h>

uint16_t hex_to_uint(const char *str) {
   int num = 0;
   while (*str != '\0'){
      num <<= 4;
      if (*str >= '0' && *str <= '9'){
         num += (*str - '0');
      } else if (*str >= 'A' && *str <= 'F'){
         num += (10 + *str - 'A');
      }else if (*str >= 'a' && *str <= 'f'){
         num += (10 + *str - 'a');
      }
      else {
         break;
      }
      str++;
   }
   return num;
}

int main() {
   char hex[10];
   scanf("%s", hex);

   printf("%u", hex_to_uint(hex));
   return 0;
}
```


### Solution 2

```c
#include <stdio.h>
#include <stdint.h>

// Convert a single hex char to its integer value
uint8_t hex_char_to_val(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    else if (c >= 'A' && c <= 'F') return c - 'A' + 10;
    else if (c >= 'a' && c <= 'f') return c - 'a' + 10;
    else return 0; // Invalid character, could return error
}

// Convert hex string to unsigned integer
uint16_t hex_to_uint(const char *str) {
    uint16_t result = 0;
    for (int i = 0; str[i] != '\0'; i++) {
        result <<= 4; // shift by 4 bits (hex digit)
        result |= hex_char_to_val(str[i]);
    }
    return result;
}

int main() {
    char hex[10];
    scanf("%s", hex);

    printf("%u", hex_to_uint(hex));
    return 0;
}
```
