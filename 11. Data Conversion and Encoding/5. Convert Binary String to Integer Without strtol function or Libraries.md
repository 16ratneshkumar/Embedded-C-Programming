# Problem 5: Convert Binary String to Integer Without strtol Function

### Problem Statement

In embedded systems, you may receive numeric data as binary strings (such as `"1101"`) via UART, configuration interfaces, or user terminals. You need to convert this binary string into an actual unsigned integer without using standard conversion functions like `strtol()` or `atoi()`.

Write a C program that reads a string of `'0'` and `'1'` characters (up to 16 bits) and converts it to its unsigned integer value.

You must not use `strtol()`, `atoi()`, `sscanf()`, or other standard conversion libraries.

### Input Format

- A single null-terminated string of `'0'` and `'1'` characters (maximum 16 characters).

### Output Format

- The converted unsigned integer printed in decimal.

### Example 1 (Standard binary value)

#### Input

```
1010
```

#### Output

```
10
```

### Example 2 (Binary value with leading zeros)

#### Input

```
0001
```

#### Output

```
1
```

### Example 3 (8-bit all ones)

#### Input

```
11111111
```

#### Output

```
255
```

### Example 4 (Zero)

#### Input

```
0
```

#### Output

```
0
```

### Explanation

To convert a binary string to an integer:

1. Initialize accumulator `val = 0`.
2. Iterate through each character of the string from left to right until the null terminator (`\0`).
3. For each character:
   - Shift the accumulated value left by 1 bit (`val <<= 1` or `val *= 2`).
   - Add the bit value (`val |= (c - '0')` or `val += (c - '0')`).
4. Print the final accumulator in decimal.

```
Example 1: "1010"
'1' -> (0 << 1) | 1 = 1
'0' -> (1 << 1) | 0 = 2
'1' -> (2 << 1) | 1 = 5
'0' -> (5 << 1) | 0 = 10
Result = 10
```

### Hints

- Traverse the string using a pointer or array index until `'\0'`.
- Convert character digit `'0'` or `'1'` to integer by subtracting `'0'`.
- Use bitwise left shift `val = (val << 1) | (str[i] - '0')` at each step.

### Solution

```c
#include <stdio.h>
#include <stdint.h>

uint16_t binary_to_uint(const char *str) {
    // Your logic here
   int num = 0;
   while (*str != '\0'){
      if (*str >= '0' && *str <= '9'){
         num = num * 2 + (*str - '0');
      }
      else {
         break;
      }
      str++;
   }
   return num;
}

int main() {
    char bin[20];
    scanf("%s", bin);

    printf("%u", binary_to_uint(bin));
    return 0;
}
```
