# 🧩 Problem 9: Pack Multiple Fields into a 16-bit Control Register

### 📝 Problem Statement

In embedded systems, multiple configuration fields are often packed into a **single register** using bit-level operations.

You are given the following field specifications to pack into a **16-bit control register**:

| Field    | Width | Bits (LSB-first) |
| -------- | ----- | ---------------- |
| Mode     | 3     | Bits 0–2         |
| Speed    | 5     | Bits 3–7         |
| Reserved | 2     | Bits 8–9 (must be 0) |
| Status   | 6     | Bits 10–15       |

Your task is to:

* Read `mode`, `speed`, and `status` from input
* Pack them into a `uint16_t` register following the given bit layout
* Ensure reserved bits (8–9) remain `0`
* Print the resulting packed value

---

### 🧾 Input Format

* `mode` → a 3-bit unsigned integer (**0–7**) for bits 0–2
* `speed` → a 5-bit unsigned integer (**0–31**) for bits 3–7
* `status` → a 6-bit unsigned integer (**0–63**) for bits 10–15

---

### 📤 Output Format

* The packed **16-bit register value** (0–65535).

---

### ✅ Examples

#### Example 1

```
Input: mode = 3, speed = 10, status = 12
Output: 12371
```

#### 🔍 Explanation

```
mode   = 3   (0b011)     → bits 0–2  → 0x0003
speed  = 10  (0b01010)   → bits 3–7  → 0x0050
status = 12  (0b001100)  → bits 10–15 → 0x3000
reserved bits 8–9 stay 0

0x0003 | 0x0050 | 0x3000 = 0x3053 = 0011000001010011 (binary) = 12371 (decimal)
```

---

#### Example 2

```
Input: mode = 7, speed = 31, status = 63
Output: 64767
```

Explanation: `0xFF | 0xF8 | 0xFC00 = 0xFCFF = 1111110011111111 (binary)`.

---

#### Example 3

```
Input: mode = 4, speed = 16, status = 8
Output: 8324
```

Explanation: `0x0004 | 0x0080 | 0x2000 = 0x2084 = 0010000010000100 (binary)`.

---

### 💡 Hints

* Each field is placed at its position with a **left shift** (`<<`): speed → bits 3–7, status → bits 10–15.
* Because the register starts at `0` and fields are combined with **bitwise OR** (`|`), the reserved bits (8–9) naturally stay `0`.

---

### 💻 Solution (C)

```c
#include <stdio.h>
#include <stdint.h>

#define SET_MODE(reg, mode) (reg | mode)
#define SET_SPEED(reg, speed) (reg | (speed << 3))
#define SET_STATUS(reg, status) (reg | (status << 10))

uint16_t pack_register(uint8_t mode, uint8_t speed, uint8_t status) {
    // Your logic here
    uint16_t reg = 0x0;
    reg = SET_MODE(reg, mode);
    reg = SET_SPEED(reg, speed);
    reg = SET_STATUS(reg, status);
    return reg;
}

int main() {
    uint8_t mode, speed, status;
    scanf("%hhu %hhu %hhu", &mode, &speed, &status);

    uint16_t reg = pack_register(mode, speed, status);
    printf("%u", reg);
    return 0;
}
```
