# 🧩 Problem 11: Extract Bit Field from 16-bit Register

### 📝 Problem Statement

Write a **C program** to extract a **5-bit field** from a **16-bit register**.

Your program should:

* Read a `uint16_t` register value
* Extract the 5-bit field from bits **4 to 8** (bit 0 = LSB)
* Print the value of that field as an **unsigned integer**

---

### 🧾 Input Format

* `reg` → a 16-bit unsigned integer (0–65535), entered in **hexadecimal**.

---

### 📤 Output Format

* The extracted **5-bit field value** (0–31).

---

### ✅ Examples

#### Example 1

```
Input: reg = 0x01F0
Output: 31
```

#### 🔍 Explanation

```
0x01F0 = 0000 0001 1111 0000
Bits 4–8 are all 1 → field = 11111 = 31
```

---

#### Example 2

```
Input: reg = 0x0000
Output: 0
```

#### 🔍 Explanation

```
All bits are 0 → field = 0
```

---

#### Example 3

```
Input: reg = 0x00B0
Output: 11
```

#### 🔍 Explanation

```
0x00B0 = 0000 0000 1011 0000
Bits 4–8 = 01011 = 11
```

---

### 💡 Hints

* **Right-shift** the register to align the field with bit 0: `reg >> 4`.
* **Mask** the low 5 bits: `& 0x1F`.

---

### 💻 Solution (C)

```c
#include <stdio.h>
#include <stdint.h>

uint8_t extract_field(uint16_t reg) {
    // Your logic here
    return (reg >> 4) & 0x1F;
}

int main() {
    uint16_t reg;
    scanf("%hx", &reg);
    printf("%u", extract_field(reg));
    return 0;
}
```
