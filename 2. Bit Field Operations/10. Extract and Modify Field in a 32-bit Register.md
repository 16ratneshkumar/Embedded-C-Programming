# 🧩 Problem 10: Extract and Modify Field in a 32-bit Register

### 📝 Problem Statement

In embedded systems, a **32-bit configuration register** often contains several packed fields.

Your task is to **extract a 5-bit field** located at bit positions **10 to 14** (bit 0 = LSB) from a 32-bit register value.

Your program should:

* Extract the 5-bit field from bits 10–14
* If the field's value is **less than 31**, **increment it by 1**
* Write the updated value back to the **same bit positions**, leaving all other bits unchanged

Use only **bitwise operations** to extract, modify, and update the register.

Bit layout (bit 0 is LSB):

```
Register: [31 ... 15 | 14 13 12 11 10 | 9 ... 0]
                        ↑  ↑  ↑  ↑  ↑ (target field)
```

---

### 🧾 Input Format

* `reg` → a 32-bit unsigned integer (0–4294967295).

---

### 📤 Output Format

* The **updated 32-bit register value**.

---

### ✅ Examples

#### Example 1

```
Input: reg = 15360 (0x00003C00)
Output: 16384 (0x00004000)
```

#### 🔍 Explanation

```
0x00003C00 = 0000 0000 0000 0000 0011 1100 0000 0000
Field at bits 10–14 = 01111 = 0xF = 15
15 < 31 → incremented to 16 (0b10000)
16 << 10 = 0x00004000, all other bits unchanged
```

---

#### Example 2

```
Input: reg = 0 (0x00000000)
Output: 1024 (0x00000400)
```

#### 🔍 Explanation

```
Field = 0
0 < 31 → incremented to 1
1 << 10 = 0x00000400 = 1024
```

---

#### Example 3

```
Input: reg = 31744 (0x00007C00)
Output: 31744 (0x00007C00)
```

#### 🔍 Explanation

```
0x00007C00 = 0000 0000 0000 0000 0111 1100 0000 0000
Field at bits 10–14 = 11111 = 31
31 is not less than 31 → register is returned unchanged
```

---

### 💡 Hints

* Build a mask to isolate the field: `mask = 0x1F << 10`.
* Extract the field with `(reg & mask) >> 10`.
* To write it back, **clear** the field bits (`reg &= ~mask`), then **OR** the shifted new value (`reg |= field << 10`).
* Guard the increment with `if (field < 31)` so the field never overflows its 5 bits.

---

### 💻 Solution (C)

```c
#include <stdio.h>
#include <stdint.h>

uint32_t update_register(uint32_t reg) {
    uint32_t mask = 0x1F << 10;
    uint32_t field = (reg & mask) >> 10;
    // Your logic here
    if ( field < 31) {
        field += 1;
        reg &= ~mask;
        reg |= (field << 10);
    }
    return reg;
}

int main() {
    uint32_t reg;
    scanf("%u", &reg);
    uint32_t updated = update_register(reg);
    printf("%u", updated);
    return 0;
}
```
