# Problem 15: void Pointer and Casting

### Problem Statement

You are writing a utility function that adds two values, where the values can be either `int` or `float`. You are given a `void*` pointing to the first and second value and a character type specifier: `'i'` for `int`, `'f'` for `float`.

The program must:

- Accept a type specifier `type`, followed by the two values.
- Cast the `void*` pointers to the appropriate type based on the specifier.
- Perform the addition and print the result, as an integer for `'i'` or a float for `'f'`.

Use proper `void*` casting and dereferencing logic.

### Input Format

- A character `type` on the first line: `'i'` for integer or `'f'` for float.
- If `type` is `'i'`, two integers on the next line.
- If `type` is `'f'`, two floats on the next line.

### Output Format

- The sum as an integer (no decimals) when `type` is `'i'`.
- The sum as a float with one decimal place when `type` is `'f'`.

### Example 1 (Integer addition)

#### Input

```
i
10 20
```

#### Output

```
30
```

### Example 2 (Float addition)

#### Input

```
f
3.5 2.5
```

#### Output

```
6.0
```

### Example 3 (Integer addition with negatives)

#### Input

```
i
-5 7
```

#### Output

```
2
```

#### Explanation

Casting each `void*` to `int*` and dereferencing gives `-5` and `7`, whose sum is `2`.

### Explanation

A `void*` is a generic pointer with no type information, so it must be cast to `int*` or `float*` before dereferencing. After the cast, the dereferenced values are added with ordinary arithmetic and printed with a format matching the chosen type.

### Hints

- Cast and dereference in one step: `*(int *)a`.
- Branch on `type` to choose the cast and the `printf` format.
- Use `%d` for integer results and `%.1f` for float results.

### Solution

```c
#include <stdio.h>

void add_and_print(void *a, void *b, char type) {
    // Write your logic here using type casting
    if (type == 'i') printf("%d",(*(int *)a + *(int *)b));
    else printf("%.1f",(*(float *)a + *(float *)b));
}

int main() {
    char type;
    scanf(" %c", &type);

    if (type == 'i') {
        int x, y;
        scanf("%d %d", &x, &y);
        add_and_print(&x, &y, type);
    } else if (type == 'f') {
        float x, y;
        scanf("%f %f", &x, &y);
        add_and_print(&x, &y, type);
    }

    return 0;
}
```
