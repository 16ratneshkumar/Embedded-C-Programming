# Problem 12: Scan Memory for Three Consecutive Increasing Values

### Problem Statement

You are given a block of memory (as an integer array) of size `n`. Write a function that scans the memory using pointers and detects the first occurrence of three consecutive increasing integers — for example `[4, 5, 6]` or `[10, 11, 12]`.

The program must:

- Accept an array of `n` integers.
- Locate the first position where the element and its two immediate successors are consecutive increasing integers (`x, x+1, x+2`).
- Print the zero-based starting index of the first such pattern, or `-1` if none exists.

Use pointer logic only, not array indexing.

### Input Format

- An integer `n`, the number of array elements.
- `n` space-separated integers.

The array contains at most 100 elements.

### Output Format

- The zero-based starting index of the first occurrence of three consecutive increasing integers.
- Print `-1` if no such pattern is found.

### Example 1 (Pattern in the middle)

#### Input

```
8
2 4 5 6 9 11 12 14
```

#### Output

```
1
```

#### Explanation

At index `1` the values are `4, 5, 6`, which are three consecutive increasing integers.

### Example 2 (No pattern)

#### Input

```
6
10 20 30 40 50 60
```

#### Output

```
-1
```

#### Explanation

No three consecutive integers satisfy `x, x+1, x+2`, so the result is `-1`.

### Example 3 (Pattern at the start)

#### Input

```
7
1 2 3 5 6 7 8
```

#### Output

```
0
```

#### Explanation

At index `0` the values are `1, 2, 3`, which are three consecutive increasing integers.

### Explanation

Walk the array from the beginning. At every position, check whether the current value equals the next value minus one and the next value equals the following value minus one, using pointer dereferences. Return the current index on the first match; if the walk finishes without a match, return `-1`.

### Hints

- Advance a pointer from the start, comparing `*p + 1 == *(p + 1)` and `*p + 2 == *(p + 2)`.
- Stop while at least three elements remain, so compare only the first `n - 2` positions.
- Keep a separate index counter to return the match position.

### Solution

```c
#include <stdio.h>

int find_pattern(int *mem, int n) {
    // Write your pointer-based logic here
    int idx = 0;
    while (n-2){
        if (((*(mem) + 1) == *(mem+1)) & ((*(mem) + 2) == *(mem+2))){
            return idx;
        }
        mem++;
        n--;
        idx++;
    }
    return -1;
}

int main() {
    int n, arr[100];
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    int res = find_pattern(arr, n);
    printf("%d", res);

    return 0;
}
```
