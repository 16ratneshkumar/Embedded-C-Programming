# Problem 4: Implement Stack Using Array with Push and Pop Operations

### Problem Statement

In embedded systems where dynamic memory is not available, stacks are typically implemented using static arrays and index tracking.

Implement a stack using a fixed-size array and support two operations:

- `push x` -> push value `x` into the stack.
- `pop` -> pop and print the top value from the stack.

Print `Stack Overflow` when trying to push while the stack is full, and `Stack Underflow` when trying to pop while the stack is empty. The stack holds at most `10` integers.

### Input Format

- An integer `n`, the number of operations.
- The next `n` lines each contain either `push x` or `pop`.

### Output Format

- For each `pop`, print the popped value on its own line.
- Print `Stack Overflow` or `Stack Underflow` on its own line when the operation cannot be performed.

### Example 1 (Push, then pop until empty)

#### Input

```
5
push 10
push 20
pop
pop
pop
```

#### Output

```
20
10
Stack Underflow
```

### Example 2 (Pop first, then push and pop)

#### Input

```
4
pop
push 5
pop
pop
```

#### Output

```
Stack Underflow
5
Stack Underflow
```

### Explanation

`top` is the index of the current top element and starts at `-1` for an empty stack. Pushing stores the value at `++top`; popping reads `stack[top]` and then decrements `top`. A full stack has `top == MAX - 1`, and an empty stack has `top == -1`.

```
Example 1: push 10 -> top 0
           push 20 -> top 1
           pop     -> prints 20, top 0
           pop     -> prints 10, top -1
           pop     -> Stack Underflow

Example 2: pop     -> Stack Underflow
           push 5  -> top 0
           pop     -> prints 5, top -1
           pop     -> Stack Underflow
```

### Hints

- Guard `push` with `top == MAX - 1` and `pop` with `top == -1`.
- Store with `stack[++top] = num;`.
- Read each operation as a line, then compare its prefix with `strncmp()`.

### Solution

```c
#include <stdio.h>
#include <stdint.h>
#include <string.h>

#define MAX 10

int stack[MAX];
int top = -1;

void push(int *stack, int num){
    if (top == (MAX-1)){
        printf("Stack Overflow\n");
    } else {
        // top++;
        stack[++top]= num;
    }
}

void pop(int *stack){
    if (top == -1){
        printf("Stack Underflow\n");
        return;
    } else {
        printf("%d\n",stack[top]);
        top--;
    }
}
void process_stack(int n) {
    // Your logic here
    char oper[32];
    int num;
    for (int i=0;i<n;i++){
        fgets(oper, sizeof(oper), stdin);
        if (strncmp(oper, "pop", 3) == 0){
            pop(stack);
        } else if(strncmp(oper, "push", 4) == 0){
            sscanf(oper + 5,"%d", &num);
            push(stack, num);
        }
    }
}

int main() {
    int n;
    scanf("%d", &n);
    getchar(); // Consume newline after number

    process_stack(n);
    return 0;
}
```
