# Problem 1: Circular Buffer Insert

### Problem Statement

You are implementing a circular buffer using a C struct.

```c
typedef struct {
    int buffer[100];   // Fixed memory for data
    int head;          // Write index
    int tail;          // Read index (not used here)
    int count;         // Number of elements in buffer
    int capacity;      // Maximum number of elements buffer can hold
} CircularBuffer;
```

Implement the function:

```c
void insert_circular(CircularBuffer *cb, int value);
```

It should:

- Insert the value at the current `head` index in the buffer.
- Advance `head` with wrap-around using modulo.
- Increment `count` after insertion.
- Do nothing if the buffer is full, that is `count == capacity`.

Reading logic is not part of this problem.

### Input Format

- `n`, the capacity of the buffer, from `1` to `100`.
- `k`, the number of values offered for insertion, from `0` to `100`.
- Then `k` integers.

### Output Format

- The stored values separated by single spaces, in buffer order from index `0` to `count - 1`.
- Nothing is printed when the buffer stays empty.

### Example 1 (Fewer inserts than capacity)

#### Input

```
5 5
10 20 30 40 50
```

#### Output

```
10 20 30 40 50
```

### Example 2 (More inserts than capacity)

#### Input

```
3 4
1 2 3 4
```

#### Output

```
1 2 3
```

### Example 3 (`head` wraps back to zero)

#### Input

```
2 4
1 2 3 4
```

#### Output

```
1 2
```

### Explanation

Once `count` reaches `capacity` the buffer is full and further inserts are dropped, so the oldest values survive and `head` stops being meaningful until a read frees a slot.

```
Example 1: capacity 5 -> count 0,1,2,3,4 -> 5 values stored, none dropped
Example 2: capacity 3 -> stores 1,2,3 -> count == capacity -> 4 is dropped
Example 3: capacity 2 -> stores 1,2 -> head wraps 1 -> 2 -> 0 -> 3 and 4 are dropped
```

### Hints

- Guard the whole body with `if (cb->count == cb->capacity) return;`.
- Wrap the write index with `cb->head = (cb->head + 1) % cb->capacity;`.
- Initialize the struct with designated initializers, for example `{.head = 0, .tail = 0, .count = 0, .capacity = n}`.

### Solution

```c
#include <stdio.h>

typedef struct {
    int buffer[100];
    int head;
    int tail;
    int count;
    int capacity;
} CircularBuffer;

void insert_circular(CircularBuffer *cb, int value) {
    // Your logic using only pointer access
    if (cb->capacity != cb->count) {
        cb->buffer[cb->head] = value;
        cb->head = (cb->head + 1) % (cb->capacity);
        cb->count++;
    }
    return;
}

int main() {
    int n, k;
    scanf("%d %d", &n, &k);

    CircularBuffer cb = { .head = 0, .tail = 0, .count = 0, .capacity = n };

    for (int i = 0; i < k; i++) {
        int val;
        scanf("%d", &val);
        insert_circular(&cb, val);
    }

    for (int i = 0; i < cb.count; i++) {
        printf("%d", cb.buffer[i]);
        if (i < cb.count - 1) {
            printf(" ");
        }
    }

    return 0;
}
```
